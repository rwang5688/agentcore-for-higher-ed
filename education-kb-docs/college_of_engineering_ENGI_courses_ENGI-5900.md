### Course Description

This advanced course provides students with a rigorous, hands-on exploration of microcontroller architecture and System-on-Chip (SoC) design using the Verilog hardware description language on Altera Field-Programmable Gate Array (FPGA) platforms. Students will progress from foundational digital logic principles to the synthesis and implementation of functional, custom-designed processor cores and peripheral interfaces within a programmable hardware environment. Emphasis is placed on professional design methodology, timing analysis, and the integration of hardware and software components characteristic of modern embedded systems development.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design, simulate, and synthesize digital systems using Verilog HDL, demonstrating proficiency in both behavioural and structural modelling paradigms on Altera FPGA development boards.
- Construct and verify functional microcontroller architectures, including ALU design, register file implementation, instruction set definition, and control unit development, from specification through to hardware deployment.
- Integrate standard peripheral interfaces — including UART, SPI, I²C, and GPIO — into a cohesive System-on-Chip design, and evaluate trade-offs in bus architecture and on-chip communication strategies.
- Apply industry-standard timing analysis and constraint methodologies using Altera Quartus Prime software to ensure reliable, timing-closure-compliant designs suitable for real-world deployment.
- Critically evaluate and document SoC design decisions with respect to area, power, and performance metrics, and communicate findings effectively through technical reports and design reviews.

### Assessment Methods

| Component | Weight |
|---|---|
| Laboratory Assignments (6 x individual lab exercises) | 30% |
| Midterm Examination (written, closed-book) | 20% |
| Design Project – Phase I: Microcontroller Core Implementation | 15% |
| Design Project – Phase II: Full SoC Integration and Demonstration | 25% |
| Final Technical Report and Design Documentation | 10% |

**Laboratory Assignments** are conducted in the FPGA Hardware Design Laboratory and require students to submit both working Verilog source code and a concise lab report for each exercise. **Design Project Phases I and II** are team-based assessments (groups of two to three students) culminating in a live hardware demonstration and peer-evaluated design review. The **Final Technical Report** must conform to IEEE documentation standards and is submitted individually. The **Midterm Examination** covers theoretical concepts in digital architecture, HDL semantics, and synthesis principles.
