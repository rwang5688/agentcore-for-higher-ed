### Course Description

This course provides a comprehensive introduction to computer programming using the Python programming language, with an emphasis on practical problem-solving and computational thinking for students across a wide range of academic disciplines. Students will explore foundational programming concepts including variables, data types, control structures, functions, and basic data manipulation, progressing toward writing functional, readable programs of moderate complexity. No prior programming experience is assumed, and the course is designed to be accessible while establishing a rigorous technical foundation appropriate for further study in computer science or data-driven fields.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- **Demonstrate fluency in core Python syntax**, including variables, operators, conditional statements, loops, and function definitions, and apply these concepts to construct well-structured programs.
- **Design and implement algorithmic solutions** to real-world problems by breaking complex tasks into logical, manageable computational steps.
- **Utilize Python's built-in data structures**, including lists, dictionaries, tuples, and sets, to store, organize, and manipulate data effectively.
- **Read, debug, and critically evaluate existing code**, identifying errors in logic and syntax and applying systematic strategies to resolve them.
- **Apply basic principles of modular programming**, including the use of libraries and reusable functions, to produce clean, maintainable, and efficient code solutions.

### Assessment Methods

Student performance will be evaluated through the following components:

| Assessment | Weight |
|---|---|
| Weekly Programming Assignments (10 total) | 30% |
| Midterm Examination | 20% |
| Laboratory Practicals (5 sessions) | 20% |
| Final Project | 20% |
| Participation and In-Class Exercises | 10% |

**Weekly Programming Assignments:** Ten structured coding assignments distributed throughout the semester, each targeting specific concepts covered in lecture. Assignments must be submitted via the departmental coding portal and will be evaluated on correctness, code quality, and adherence to specified style guidelines.

**Midterm Examination:** A written and practical examination covering all material from Weeks 1–7, including syntax comprehension, code tracing, debugging exercises, and short programming problems completed in a supervised environment.

**Laboratory Practicals:** Five assessed laboratory sessions in which students complete guided programming tasks under timed conditions, demonstrating applied competency with core course concepts. Labs are conducted in the department's computing facilities.

**Final Project:** Students will independently design and develop a Python program of their choice that addresses a defined problem or task of personal or professional relevance. Submissions must include the source code, a written technical report (minimum 1,500 words), and a brief oral presentation delivered during the final examination period.

**Participation and In-Class Exercises:** Regular attendance and active engagement in lecture discussions and ungraded in-class coding exercises contribute to this component. Engagement quality, not merely attendance, will be considered in grading.
