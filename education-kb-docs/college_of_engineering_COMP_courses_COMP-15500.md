### Course Description

This course provides an advanced exploration of data analysis methodologies using the Python programming language, with an emphasis on applied computational techniques for processing, visualizing, and interpreting complex datasets. Students will develop proficiency with industry-standard Python libraries and frameworks while engaging with real-world data problems drawn from scientific, business, and engineering domains. The course bridges theoretical foundations in statistics and data science with practical, hands-on programming experience appropriate for graduate-level study.

---

### Learning Objectives

Upon successful completion of COMP-15500, students will be able to:

- Design and implement robust data pipelines using Python libraries such as NumPy, pandas, and SciPy to clean, transform, and prepare large-scale datasets for analysis
- Apply statistical modeling and inferential techniques programmatically, interpreting results within the appropriate domain context
- Construct meaningful and publication-quality data visualizations using tools such as Matplotlib and Seaborn to communicate analytical findings effectively
- Evaluate and select appropriate machine learning and predictive modeling approaches using scikit-learn for structured data problems
- Critically assess the ethical implications of data collection, analysis, and interpretation, including issues of bias, privacy, and reproducibility in computational research

### Prerequisites

Students enrolling in COMP-15500 must have completed the following, or obtained written permission from the course instructor:

- **COMP-10200: Introduction to Programming** or demonstrated equivalent programming experience
- **COMP-21400: Foundations of Data Structures and Algorithms**
- **MATH-20100: Statistics and Probability for Computing** or **MATH-20300: Applied Statistical Methods**
- Graduate standing or advanced undergraduate status (Level 500 or above) within the College of Engineering or a closely related discipline

Students without a formal Python background but with equivalent experience in another programming language may be admitted at instructor discretion following a skills assessment during the first week of the term.

### Assessment Methods

Student performance in COMP-15500 will be evaluated through a combination of the following components:

| Assessment Component | Weight | Description |
|---|---|---|
| Programming Assignments (×5) | 35% | Weekly structured coding tasks reinforcing lecture content and library usage |
| Midterm Examination | 15% | Written and computational exam assessing foundational concepts and library fluency |
| Data Analysis Project — Proposal | 5% | A formal written proposal outlining dataset selection, research questions, and methodology |
| Data Analysis Project — Final Submission | 30% | A comprehensive analytical report and fully documented codebase addressing a self-directed research question using real-world data |
| Project Presentation | 10% | A 15-minute oral presentation of final project findings delivered to peers and faculty |
| Participation & Lab Engagement | 5% | Active contribution to in-class discussions, lab sessions, and peer code review exercises |

All programming assignments must be submitted via the university's designated code repository platform. Late submissions will be penalised at a rate of 10% per 24-hour period unless an extension has been formally approved.
