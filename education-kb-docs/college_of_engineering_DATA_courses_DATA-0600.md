### Course Description

This graduate-level course provides a rigorous examination of relational database systems and Structured Query Language (SQL) as foundational tools for data science practice. Students explore database design principles, query optimization, and advanced data retrieval techniques within the context of large-scale analytical workflows. Emphasis is placed on integrating database competencies with modern data science pipelines, including interaction with NoSQL systems and cloud-hosted data environments.

---

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement normalized relational database schemas suitable for data science applications, applying entity-relationship modeling and appropriate indexing strategies.
- Write complex SQL queries incorporating advanced features such as window functions, subqueries, common table expressions (CTEs), and stored procedures to extract and transform data at scale.
- Evaluate and compare relational and non-relational (NoSQL) database architectures, selecting appropriate systems based on data structure, volume, and analytical requirements.
- Integrate SQL-based data extraction workflows with downstream data science tools, including Python libraries (e.g., SQLAlchemy, Pandas) and business intelligence platforms.
- Critically assess query performance and apply optimization techniques, including execution plan analysis and index tuning, to support efficient large-dataset operations.

### Prerequisites

Students enrolling in DATA-0600 must have completed the following or demonstrate equivalent competency:

- **DATA-0400: Foundations of Data Science** or equivalent introductory graduate coursework in data science methodology
- **CS-0350: Introduction to Programming for Data Applications** or demonstrated proficiency in Python or a comparable scripting language
- **MATH-0310: Probability and Statistical Reasoning** or equivalent coursework in applied statistics
- Prior exposure to any relational database system or completion of a recognized online credential in SQL fundamentals (documented evidence required)

Students uncertain about their preparation are encouraged to consult with their assigned faculty advisor or contact the instructional team prior to enrollment.
