## Course Description

**COMP-10200 | Introduction to Computing**
*Credit Points: 4 | Department of Computer Science | College of Engineering*

---

### Course Description

This course provides students with a foundational understanding of computing principles, including hardware architecture, software systems, algorithmic thinking, and the role of computing in modern society. Students will explore core programming concepts, data representation, and problem-solving strategies through a combination of theoretical instruction and hands-on laboratory practice. No prior experience with programming or computer science is assumed, making this an accessible entry point for students pursuing study in computing-related disciplines.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a working understanding of fundamental computing concepts, including binary representation, Boolean logic, and the organisation of computer hardware and software systems
- Design and implement basic algorithms and translate logical problem-solving processes into structured, functional code using an introductory programming language
- Identify and apply core programming constructs including variables, conditionals, loops, functions, and basic data structures
- Evaluate the societal, ethical, and practical implications of computing technologies in contemporary professional and everyday contexts
- Utilise standard development tools and computing environments to write, test, and debug simple programs independently

### Prerequisites

Students enrolling in COMP-10200 must satisfy the following requirements:

- Completion of or concurrent enrolment in **MATH-10100: Foundations of Mathematics for Technology** or equivalent qualification as determined by the Department of Computer Science
- Demonstrated basic digital literacy (word processing, file management, web navigation) as assessed during orientation or by departmental placement review
- No prior programming experience is required; however, students are strongly encouraged to complete the self-paced **Peculiar U Digital Readiness Module** available through the university's learning management system prior to the first week of class

### Assessment Methods

Student performance in COMP-10200 will be evaluated through the following components:

| Component | Weight |
|---|---|
| Weekly Programming Laboratories (10 × 3%) | 30% |
| Midterm Written Examination | 20% |
| Group Project: Computing Solutions Proposal | 15% |
| Final Programming Project | 20% |
| Final Examination | 15% |

**Weekly Programming Laboratories** are completed during scheduled lab sessions and assess students' ongoing application of concepts introduced in lecture. Collaboration is permitted in accordance with the departmental academic integrity policy.

**Midterm and Final Examinations** are closed-book assessments covering theoretical content, including computing concepts, algorithmic logic, and data representation. Students may bring one hand-written reference sheet (A4, both sides) to the final examination only.

**Group Project** requires teams of three to four students to identify a real-world problem and propose a computing-based solution, culminating in a written report and a brief oral presentation delivered to the class.

**Final Programming Project** is an individual assignment in which students design, implement, and document a small software application demonstrating mastery of the core programming skills developed throughout the course.
