### Course Description

This course introduces students to the foundational principles and practices of data science using the Python programming language, covering the complete data workflow from acquisition and cleaning through analysis and visualization. Students will develop practical proficiency with core Python libraries and learn to apply statistical reasoning to real-world datasets drawn from diverse domains. Emphasis is placed on reproducible, well-documented analytical workflows and the ethical responsibilities inherent in working with data.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Write and execute Python scripts utilizing standard data science libraries — including NumPy, pandas, and Matplotlib — to manipulate, analyze, and visualize structured datasets
- Apply fundamental statistical concepts, including descriptive statistics, probability distributions, and correlation analysis, to draw meaningful and defensible inferences from data
- Perform the full data preparation pipeline, encompassing data loading, cleaning, transformation, and aggregation, in preparation for downstream analysis
- Construct clear and informative data visualizations appropriate to the data type and intended audience, and communicate analytical findings in both written and oral formats
- Identify and articulate basic ethical considerations in data science practice, including issues of data privacy, bias, and responsible interpretation of results

### Assessment Methods

Student performance will be evaluated through the following components:

| Component | Weight |
|---|---|
| Weekly Programming Assignments (10 × 4%) | 40% |
| Midterm Examination | 20% |
| Data Analysis Project (individual) | 25% |
| Final Oral Presentation & Report | 15% |

**Weekly Programming Assignments:** Ten structured coding assignments submitted via the course learning management system, each targeting a specific concept or toolset covered during that week's instruction.

**Midterm Examination:** A closed-book written and practical examination assessing students' understanding of core statistical concepts, Python syntax, and data manipulation techniques covered in the first half of the course.

**Data Analysis Project:** An individual project in which students select a publicly available dataset, define an analytical question, conduct a complete analysis using Python, and produce a reproducible Jupyter Notebook with full documentation of their methodology and findings.

**Final Oral Presentation & Report:** A formal 10-minute presentation and accompanying written report summarizing the student's data analysis project, delivered to the class and evaluated by the instructional team on clarity, technical accuracy, and quality of insight.

### Required Materials and Textbooks

Students are required to obtain the following materials prior to the first week of class:

A free, preconfigured computing environment will be made available through Peculiar U's Virtual Lab Portal for students who require it. All required software, including Anaconda Distribution and Jupyter Notebook, is freely available and installation guidance will be provided during the first laboratory session.
