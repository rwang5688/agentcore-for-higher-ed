## Course Description

### Course Description

This advanced course provides students with comprehensive instruction in developing applications for iOS 9 using the Swift programming language, covering the full lifecycle of mobile application development from design to deployment on the Apple App Store. Students will explore core iOS frameworks, user interface design principles using UIKit, and best practices for writing clean, efficient Swift code in a professional development environment. Special emphasis is placed on real-world application architecture, data persistence, networking, and integrating native iOS 9 features into polished, market-ready applications.

### Learning Objectives

By the end of this course, students will be able to:

- Design, develop, and deploy fully functional iOS 9 applications using Swift, demonstrating proficiency in Xcode and the Apple development toolchain
- Apply fundamental and advanced Swift programming concepts, including optionals, closures, protocols, and generics, within the context of mobile application development
- Implement complex user interfaces using UIKit, Auto Layout, and iOS 9 navigation paradigms that conform to Apple's Human Interface Guidelines
- Integrate core iOS frameworks such as Core Data, Core Location, and URLSession to build data-driven, networked applications
- Evaluate and apply appropriate architectural design patterns, including MVC and delegation, to produce maintainable and scalable iOS application codebases

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- **COMP-3210: Object-Oriented Programming** or equivalent with a grade of C or higher
- **COMP-3450: Mobile Computing Fundamentals**
- **COMP-4120: Data Structures and Algorithms**
- Demonstrated familiarity with at least one compiled, statically-typed programming language
- Access to an Apple Mac computer running OS X El Capitan (10.11) or later is required for participation in this course

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (5 total) | 35% |
| Midterm Examination | 15% |
| Group Project – Full iOS Application | 30% |
| Final Technical Portfolio & Code Review | 15% |
| Participation & Lab Attendance | 5% |

**Programming Assignments:** Five progressively complex individual coding assignments will be issued throughout the semester, each targeting specific iOS frameworks and Swift language features covered in lecture.

**Midterm Examination:** A written and practical examination assessing theoretical understanding of Swift language architecture, memory management, and iOS application lifecycle concepts.

**Group Project:** Teams of three to four students will design, develop, and present a fully functional iOS 9 application. A formal project proposal, progress check-in, and final presentation with live demonstration are required components.

**Final Technical Portfolio & Code Review:** Students will compile a documented portfolio of their work from the course and participate in an individual code review session with the instructional team, demonstrating mastery of course concepts and the ability to articulate technical decisions.
