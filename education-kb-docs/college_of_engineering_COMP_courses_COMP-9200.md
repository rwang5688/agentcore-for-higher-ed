## Course Description

### Course Description

COMP-9200: Introduction to Computer Science: Programming Methodology provides an advanced exploration of foundational programming principles, algorithmic thinking, and software design paradigms within a rigorous academic framework. Students will examine structured, object-oriented, and functional programming methodologies, with emphasis on writing efficient, maintainable, and scalable code across multiple programming environments. This course is designed for graduate-level learners seeking to consolidate and critically evaluate core computational principles in preparation for advanced specialisation in software engineering, systems design, or computer science research.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a comprehensive understanding of core programming methodologies, including structured, object-oriented, and functional paradigms, and apply each appropriately to solve complex computational problems
- Design and implement algorithms with consideration for time and space complexity, applying formal analysis techniques to evaluate and compare solution efficiency
- Develop well-structured, documented, and testable software using professional coding standards, version control practices, and debugging methodologies
- Critically evaluate existing codebases to identify design inefficiencies, anti-patterns, and opportunities for refactoring and optimisation
- Apply abstraction and modular design principles to construct scalable software systems that accommodate changing requirements and real-world constraints

### Prerequisites

Students enrolling in COMP-9200 must have satisfied the following prerequisites prior to registration:

- Completion of **COMP-7100: Foundations of Computational Theory** or equivalent with a minimum grade of B
- Completion of **COMP-7250: Data Structures and Algorithm Design** or equivalent
- Demonstrated proficiency in at least one high-level programming language (Python, Java, or C++) as verified by departmental assessment or prior coursework
- Graduate standing within the College of Engineering or written permission from the course coordinator

Students who are uncertain about prerequisite equivalency are encouraged to consult with the Department of Computer Science advising office prior to enrolment.

### Assessment Methods

Student performance in COMP-9200 will be evaluated through the following assessment components:

- **Programming Assignments (35%)** — A series of five progressively complex programming assignments requiring students to implement, test, and document software solutions aligned with each of the course's major methodology units. Assignments are submitted via the departmental code repository system and are assessed on correctness, efficiency, and coding standards compliance.
- **Midterm Examination (20%)** — A closed-book written examination covering theoretical foundations of programming methodology, algorithmic analysis, and design principles addressed in the first half of the course.
- **Software Design Project (30%)** — A substantial individual or paired capstone project requiring students to design, implement, and present a fully documented software application of meaningful complexity. Project submissions must include source code, technical documentation, a design rationale report, and an oral defence before the instructional team.
- **Final Examination (15%)** — A comprehensive closed-book examination assessing students' ability to analyse code samples, evaluate design decisions, and apply course concepts to novel programming scenarios.

All assessments must be submitted by the deadlines stipulated in the course schedule. Late submissions will be penalised at a rate of 5% per calendar day unless an extension has been formally approved by the course coordinator.
