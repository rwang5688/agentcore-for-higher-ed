## Course Description

### Course Description

This course provides a comprehensive introduction to the fundamental principles of computer architecture, examining the structural and functional organization of modern computing systems as understood through the lens of early 2010s hardware paradigms. Students will explore the relationship between hardware design and software performance, including instruction set architectures, memory hierarchies, and processor design methodologies. Emphasis is placed on developing a rigorous analytical framework for evaluating architectural trade-offs in contemporary and emerging computing environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a thorough understanding of instruction set architecture (ISA) design principles, including RISC and CISC paradigms, and evaluate their respective performance implications
- Analyze the structure and operation of the CPU pipeline, identifying hazards and applying mitigation strategies such as forwarding, stalling, and branch prediction
- Evaluate memory hierarchy design, including cache organization, virtual memory systems, and the performance trade-offs associated with each level of the hierarchy
- Apply quantitative methodologies, including Amdahl's Law and CPU performance equations, to assess and compare architectural design decisions
- Synthesize knowledge of parallel processing architectures, including multicore and vector processing systems, and articulate their significance within the broader landscape of high-performance computing

---

### Prerequisites

Given the advanced level designation of this course (Level 8735), students are expected to have substantial foundational preparation. The following prerequisites are required prior to enrollment:

- **COMP-6200: Digital Logic and Circuit Design** — Students must demonstrate proficiency in Boolean algebra, combinational and sequential circuit analysis, and basic hardware description languages (HDLs)
- **COMP-6450: Systems Programming and Low-Level Computing** — Competency in assembly language programming, memory management, and low-level I/O operations is essential
- **COMP-6310: Data Structures and Algorithm Analysis** — A solid understanding of algorithmic complexity and data organization is required to contextualize architectural performance discussions
- **MATH-5100: Discrete Mathematics for Computer Science** — Proficiency in logic, set theory, and combinatorics as applied to computing contexts

Students who have not completed the above prerequisites or equivalent coursework approved by the department must seek written permission from the course coordinator before registering.
