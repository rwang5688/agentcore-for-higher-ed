## Course Description

### Course Description

This course provides a comprehensive introduction to mobile application development for Apple's iOS platform, with a focus on building functional apps for iPhone and iPad using the tools and frameworks available as of 2013, including Xcode and Objective-C. Students will engage in collaborative, project-based learning to design, develop, and deploy mobile applications while gaining foundational knowledge of the iOS SDK and Apple's Human Interface Guidelines. Emphasis is placed on teamwork, iterative development practices, and producing polished applications suitable for submission to the App Store.

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement native iOS applications using Objective-C and the iOS SDK within the Xcode development environment
- Apply the Model-View-Controller (MVC) architectural pattern to structure well-organised, maintainable mobile applications
- Utilise core iOS frameworks including UIKit, Core Data, and Core Location to build feature-rich applications for iPhone and iPad
- Collaborate effectively in small development teams using version control systems and agile development methodologies
- Evaluate and refine application interfaces in accordance with Apple's Human Interface Guidelines to ensure a high-quality user experience

### Prerequisites

Students must have successfully completed the following before enrolling in COMP-3100:

- **COMP-2010: Introduction to Object-Oriented Programming** or equivalent, with a grade of C or higher
- **COMP-2150: Data Structures and Algorithms**
- **COMP-2200: Software Design Principles**

Familiarity with a C-based programming language is strongly recommended. Students with no prior programming experience will not be adequately prepared for this course. Instructor consent may be required for students whose prerequisite coursework was completed at another institution.

### Assessment Methods

| Assessment Component | Weight |
|---|---|
| Weekly Lab Exercises | 15% |
| Midterm Examination | 20% |
| Individual Programming Assignments (×3) | 25% |
| Collaborative App Development Project | 30% |
| Project Presentation and Demonstration | 10% |

**Weekly Lab Exercises:** Short, structured programming tasks completed during scheduled lab sessions, designed to reinforce lecture content and build practical familiarity with iOS development tools.

**Midterm Examination:** A written and practical examination covering theoretical concepts including memory management, MVC architecture, iOS application lifecycle, and Objective-C syntax.

**Individual Programming Assignments:** Three graded assignments of increasing complexity, each requiring the development of a small standalone iOS application demonstrating mastery of specific course topics.

**Collaborative App Development Project:** Completed in teams of three to four students, this capstone project requires the design and development of a fully functional iOS application from initial concept through to a submission-ready build. Teams will maintain a shared code repository and submit iterative builds throughout the semester along with design documentation and a testing report.

**Project Presentation and Demonstration:** Teams present their completed application to the class and a panel of departmental faculty, demonstrating core functionality and discussing design decisions and challenges encountered during development.

Access to a physical iOS device is recommended but not mandatory, as the iOS Simulator bundled with Xcode is sufficient for the majority of coursework. An Apple Developer Program membership (student rate) will be required for the final project submission phase; details will be provided in the first week of classes.
