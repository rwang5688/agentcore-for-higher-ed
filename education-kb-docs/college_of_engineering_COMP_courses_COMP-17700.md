## Course Description

### Course Description

COMP-17700: Using Python to Access Web Data provides students with a foundational understanding of how to retrieve, parse, and process data from the internet using the Python programming language. Students will explore core web technologies including HTTP protocols, APIs, and structured data formats such as XML and JSON, applying these concepts through hands-on programming exercises. This course equips learners with practical, real-world skills for data collection and web-based application development within a modern computing environment.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Write Python programs that retrieve data from web-based sources using HTTP requests and standard networking libraries
- Parse and extract meaningful information from structured data formats including JSON, XML, and HTML
- Interact with web-based APIs and understand authentication mechanisms such as OAuth and API key management
- Apply regular expressions and string processing techniques to clean and transform raw web data
- Demonstrate an understanding of web scraping ethics, rate limiting, and responsible data access practices

---

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- **COMP-11200: Introduction to Programming** or equivalent foundational programming coursework
- **COMP-14400: Python Programming Fundamentals** or demonstrated proficiency in Python as assessed by departmental placement
- A minimum grade of **C** or better in all prerequisite courses is required

Students with no prior programming experience are strongly encouraged to complete introductory coursework before enrolling. Familiarity with basic command-line operations and file system navigation is recommended but not strictly required.

### Assessment Methods

Student performance will be evaluated through the following components:

| Assessment Component | Weight |
|---|---|
| Weekly Programming Assignments (8 total) | 30% |
| Midterm Examination | 15% |
| Lab Practicals (4 total) | 20% |
| Web Data Capstone Project | 25% |
| Participation and In-Class Exercises | 10% |

**Weekly Programming Assignments** require students to write, test, and submit Python scripts addressing web data retrieval scenarios of increasing complexity. **Lab Practicals** are timed, supervised coding sessions held in the department computing laboratory. The **Web Data Capstone Project** is a culminating individual project in which students design and implement a Python application that collects, processes, and presents data sourced from at least two publicly accessible web APIs or data streams. A written project report is required alongside the submitted codebase. The **Midterm Examination** includes both multiple-choice conceptual questions and short written code analysis sections.
