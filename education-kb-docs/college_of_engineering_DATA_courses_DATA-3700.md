## Course Description

### Course Description

This course provides a comprehensive introduction to R programming for data science applications, covering foundational syntax, data structures, and the use of R's extensive ecosystem of statistical and visualization libraries. Students will develop practical skills in data wrangling, exploratory analysis, and reproducible reporting using industry-standard tools and workflows. Emphasis is placed on applying R to real-world datasets drawn from a variety of domains, preparing students for advanced coursework in statistical modeling and machine learning.

---

### Learning Objectives

By the end of this course, students will be able to:

- Write, debug, and optimize R scripts using core language constructs including control flow, functions, and object-oriented paradigms
- Import, clean, reshape, and manipulate datasets using the tidyverse suite of packages
- Produce publication-quality visualizations and interactive graphics using ggplot2 and related tools
- Conduct reproducible data analyses and generate dynamic reports using R Markdown and Quarto
- Apply fundamental statistical techniques in R, including descriptive statistics, hypothesis testing, and basic regression modeling

### Prerequisites

Students must have successfully completed the following before enrolling in DATA-3700:

- **DATA-2200: Introduction to Data Science** or equivalent, with a minimum grade of C+
- **MATH-2310: Probability and Statistics I** or equivalent
- Working familiarity with at least one programming language (Python, Java, or similar) is strongly recommended

Students who have not completed the listed prerequisites must obtain written approval from the supervising instructor prior to registration.

### Assessment Methods

| Component | Weight |
|---|---|
| Weekly Programming Assignments (10 total) | 30% |
| Midterm Examination | 20% |
| Data Analysis Project (Part I – Proposal & EDA) | 10% |
| Data Analysis Project (Part II – Full Report & Presentation) | 25% |
| Final Examination | 15% |

**Weekly Programming Assignments** are submitted via the course portal and are assessed on correctness, code efficiency, and adherence to documented coding standards. **The Data Analysis Project** is completed individually or in pairs and requires students to identify a real-world dataset, formulate analytical questions, and produce a fully reproducible R Markdown report accompanied by a short in-class presentation. Both examinations are closed-book but permit a single hand-written reference sheet.

### Required Materials

Students are expected to acquire the following materials prior to the first week of instruction:

- **Harwick, P. J., & Solander, T. (2022).** *Data Fluency with R: A Practical Guide to Analysis and Visualization* (3rd ed.). Northgate Academic Press. ISBN 978-1-55234-881-4
- **Okonkwo, D. F. (2021).** *The Tidy Data Practitioner: Workflows, Wrangling, and Reproducible Science in R.* Elmridge Publishing. ISBN 978-0-74819-203-7
- **Supplementary Course Reader:** *DATA-3700 Selected Readings in Applied R Programming* — compiled by the instructional team and available for purchase at the Peculiar U campus bookstore or as a digital download via the course portal

All required software, including R (version 4.3 or later) and RStudio Desktop, is free and open-source. Installation guides are provided on the course portal. Students are expected to bring a laptop capable of running RStudio to all lab sessions.
