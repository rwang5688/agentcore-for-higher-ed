## Course Description

**COMP-8800 | Introduction to Computer Graphics & GPU Programming**
*Credit Points: 3 | Department: Computer Science | College of Engineering*

---

This course provides a rigorous foundation in the principles and practices of real-time and offline computer graphics, with a particular emphasis on modern GPU architectures and parallel programming paradigms. Students will explore the full rendering pipeline, shader development, and the mathematical underpinnings of 3D scene construction, illumination models, and rasterization. Practical laboratory components bridge theoretical concepts with applied GPU programming using contemporary graphics APIs and compute frameworks.

---

### Course Description

This course introduces graduate-level students to the core concepts of computer graphics and GPU-accelerated computing, covering topics including the graphics pipeline, geometric transformations, lighting and shading models, texture mapping, and ray tracing fundamentals. Emphasis is placed on hands-on shader programming using GLSL and HLSL, as well as general-purpose GPU (GPGPU) computing through frameworks such as CUDA and OpenCL. By the end of the course, students will be equipped to design and implement sophisticated rendering systems and leverage GPU parallelism in computationally intensive applications.

---

### Learning Objectives

Upon successful completion of COMP-8800, students will be able to:

- **Explain and apply** the stages of the modern programmable graphics pipeline, including vertex processing, rasterization, fragment shading, and output merging, to construct functional real-time rendering systems.
- **Develop and debug** custom vertex, geometry, and fragment shaders using GLSL and/or HLSL, demonstrating proficiency in implementing physically-based lighting models, shadow techniques, and post-processing effects.
- **Analyze GPU hardware architecture** — including warp/wavefront scheduling, memory hierarchies, and compute unit organization — to write optimized, high-throughput parallel programs using CUDA or OpenCL.
- **Implement foundational graphics algorithms**, including affine and projective transformations, Bézier and B-spline curve evaluation, texture filtering, and recursive ray tracing, from mathematical specification to executable code.
- **Design and present** a substantial graphics programming project that integrates multiple course concepts, demonstrating the ability to evaluate performance trade-offs and make informed architectural decisions for real-time or offline rendering scenarios.

### Prerequisites

Students enrolling in COMP-8800 must have satisfied the following prerequisites prior to registration. Waivers may be granted by the Department Chair upon petition.

- **COMP-6110: Data Structures & Algorithm Analysis** or equivalent graduate-level programming foundations course
- **COMP-6450: Systems Programming & Memory Management** or demonstrated proficiency in C/C++ programming
- **MATH-5320: Linear Algebra for Engineers** — a solid working knowledge of vectors, matrices, transformations, and coordinate systems is essential throughout this course
- **MATH-5410: Multivariable Calculus** or equivalent (recommended, not strictly required)
- Prior experience with any compiled programming language (C, C++, Java, Rust) at an intermediate or higher level; students without C++ experience are strongly advised to complete the department's self-paced C++ Bridge Module before the first week of instruction

*Note: This course is classified at Level 7635 and is intended for advanced undergraduate students in their final year or graduate students in the early stages of a postgraduate programme. Students without the recommended mathematical preparation may find the course progression challenging.*

### Assessment Methods

Assessment in COMP-8800 is designed to evaluate both theoretical understanding and practical implementation capability. All submissions must comply with the Peculiar U Academic Integrity Policy.

| Assessment Component | Weight | Details |
|---|---|---|
| Programming Assignments (×4) | 40% | Four incremental coding assignments covering: (1) the OpenGL pipeline and basic scene rendering, (2) custom shader development, (3) ray tracing implementation, and (4) GPGPU programming with CUDA/OpenCL |
| Midterm Examination | 20% | Written closed-book examination covering pipeline theory, transformation mathematics, and shading models (Weeks 1–7) |
| Final Examination | 20% | Comprehensive written examination with short-answer and extended-response questions; includes GPU architecture analysis problems |
| Capstone Graphics Project | 15% | A self-directed rendering or GPGPU project completed individually or in pairs; includes a written technical report and a 15-minute in-class demonstration and Q&A |
| Weekly Lab Participation | 5% | Active engagement in supervised laboratory sessions; assessed on completion
