## Course Description

### Course Description

COMP-8900 provides an intensive introduction to the foundational principles of computer science with a focus on practical programming skills using the Python language. Students will explore core computational concepts including algorithmic thinking, data structures, control flow, and object-oriented design within a rigorous academic framework suited to the graduate level. The course is designed to equip students from diverse disciplinary backgrounds with the technical literacy and programming proficiency required for advanced study and professional application in computational fields.

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate a working understanding of fundamental computer science concepts, including abstraction, algorithm design, and computational complexity
- Write, test, and debug well-structured Python programs employing variables, control structures, functions, and modules
- Apply object-oriented programming principles—including encapsulation, inheritance, and polymorphism—to design modular and reusable code
- Implement and manipulate common data structures such as lists, dictionaries, stacks, and queues to solve practical computational problems
- Critically evaluate the efficiency and correctness of algorithmic solutions and communicate technical reasoning clearly in both written and oral formats

### Prerequisites

Given the graduate-level standing of this course (Level 7735), students are expected to have completed the following or demonstrate equivalent competency prior to enrolment:

- Completion of an undergraduate degree in any discipline from an accredited institution
- MATH-3200: Discrete Mathematics and Logic, or equivalent foundational coursework in formal reasoning and mathematical proof
- Prior exposure to at least one programming language or completion of a recognised introductory programming module (e.g., a verified online certification in programming fundamentals may be considered at the discretion of the instructor)
- Students without a formal computing background are strongly encouraged to complete the department's non-credit Python Bootcamp workshop offered at the start of each semester

Students who are uncertain whether their background meets these requirements are advised to contact the Department of Computer Science for a prerequisite waiver review.

### Assessment Methods

Student performance will be evaluated through a combination of formative and summative assessments designed to measure both theoretical understanding and practical programming ability:

- **Programming Assignments (40%)** — Six graded programming assignments distributed throughout the semester, each targeting specific topics such as recursion, data structure manipulation, and object-oriented design. Assignments are submitted via the department's automated grading portal and assessed on correctness, code quality, and documentation.
- **Midterm Examination (20%)** — A closed-book written examination covering theoretical concepts from the first half of the course, including algorithm analysis, control flow, and foundational data structures. The examination will include a mix of short-answer and code-tracing questions.
- **Final Project (25%)** — A substantial individual or paired programming project in which students design, implement, and present a Python application addressing a problem of their choosing within parameters approved by the instructor. A written technical report and a brief oral presentation are required components of the final project submission.
- **Final Examination (15%)** — A comprehensive closed-book examination covering all course material, with emphasis on integrative problem-solving and code analysis.

All assessments must be submitted or attended as scheduled. Late submissions will incur a penalty of 10% per day unless a formal extension has been approved. Academic integrity policies apply strictly to all programming work; use of unauthorised generative AI tools in assessments is prohibited unless explicitly stated otherwise by the course instructor.
