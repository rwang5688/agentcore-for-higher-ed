## Course Description

### Course Description

COMP-7100 provides a rigorous treatment of the mathematical foundations underlying modern machine learning algorithms, with an emphasis on practical implementation using the Python programming language. Students will develop fluency in linear algebra, multivariate calculus, probability theory, and optimization techniques as they apply directly to the design, analysis, and deployment of machine learning models. Through a combination of theoretical instruction and hands-on computational exercises, this course bridges the gap between abstract mathematical concepts and their real-world applications in data science and artificial intelligence.

---

### Learning Objectives

By the end of this course, students will be able to:

- Apply core concepts from linear algebra — including matrix decomposition, eigenvalues, and vector spaces — to machine learning problems such as dimensionality reduction and principal component analysis
- Utilize multivariate calculus and gradient-based optimization techniques, including backpropagation and stochastic gradient descent, to train and evaluate machine learning models
- Implement probabilistic models and apply statistical reasoning — including Bayesian inference, probability distributions, and maximum likelihood estimation — to real-world datasets using Python
- Translate mathematical formulations of machine learning algorithms into efficient, well-documented Python code using industry-standard libraries such as NumPy, SciPy, and SymPy
- Critically analyze the mathematical assumptions and computational trade-offs inherent in common machine learning methods, and select appropriate techniques for a given problem domain

Students enrolling in COMP-7100 must have satisfied the following prerequisites:

Students who are uncertain whether their background satisfies these requirements are encouraged to consult with the course instructor prior to registration.

### Assessment Methods

Student performance will be evaluated through the following components:

| Assessment | Weight |
|---|---|
| Weekly Problem Sets (10 total) | 25% |
| Midterm Examination | 20% |
| Computational Lab Assignments (4 total) | 25% |
| Final Research & Implementation Project | 25% |
| Participation & In-Class Quizzes | 5% |

**Weekly Problem Sets:** Ten graded problem sets will be assigned throughout the semester, each requiring students to solve mathematical proofs, derivations, and applied problems by hand and, where specified, computationally in Python.

**Midterm Examination:** A closed-book, in-class examination covering linear algebra, calculus, and probability as applied to machine learning. A formula reference sheet will be provided.

**Computational Lab Assignments:** Four structured lab assignments will require students to implement mathematical algorithms from scratch in Python, with written reports analyzing results, performance, and theoretical justifications.

**Final Research & Implementation Project:** Working individually or in pairs (with instructor approval), students will select a machine learning algorithm or application domain, derive or extend its mathematical basis, implement a full solution in Python, and submit both a formal written report and a live code demonstration. Project proposals must be approved by Week 6.
