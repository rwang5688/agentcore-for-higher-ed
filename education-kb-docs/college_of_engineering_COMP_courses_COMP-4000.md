## Course Description

### Course Description

COMP-4000: Computer Systems provides an in-depth exploration of the architecture, organization, and operational principles underlying modern computing systems, with emphasis on the interaction between hardware and software layers. Students examine processor design, memory hierarchies, input/output subsystems, and operating system fundamentals as integrated components of a cohesive computational environment. The course bridges theoretical foundations with practical systems-level programming, equipping students to reason rigorously about performance, efficiency, and correctness in complex computing environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Analyze the functional components of computer architecture, including CPU design, instruction set architectures, and pipelining, and explain how these components interact to execute programs.
- Evaluate memory hierarchy design—spanning registers, caches, main memory, and secondary storage—and apply this understanding to optimize program performance and resource utilization.
- Demonstrate proficiency in systems-level programming, including low-level I/O management, process and thread coordination, and direct manipulation of memory using languages such as C and assembly.
- Explain the role of the operating system as an intermediary between hardware and application software, including process scheduling, virtual memory management, and concurrency control.
- Design and implement modest systems software components, critically assessing trade-offs in performance, reliability, and scalability through empirical measurement and analysis.

### Prerequisites

Students must have successfully completed the following prior to enrollment in COMP-4000:

- **COMP-2210: Data Structures and Algorithms** — Foundational understanding of algorithmic thinking and core data structure implementation is assumed throughout the course.
- **COMP-2450: Introduction to Computer Organization** — Students are expected to have prior exposure to binary arithmetic, basic logic circuits, and introductory assembly language.
- **COMP-2600: Systems Programming in C** — Proficiency in C programming, including pointer arithmetic, dynamic memory allocation, and file I/O, is essential for lab and project components.
- A minimum cumulative GPA of 2.0 in all Computer Science coursework is required. Students who have not met prerequisites must obtain written departmental approval before registering.

### Assessment Methods

Student performance in COMP-4000 is evaluated through the following components:

| Component | Weight |
|---|---|
| Midterm Examination | 20% |
| Final Examination | 25% |
| Programming Projects (3) | 35% |
| Lab Assignments (6) | 15% |
| Participation & Quizzes | 5% |

**Examinations:** Two written examinations assess conceptual understanding of architecture, operating system principles, and memory systems. The final examination is cumulative and may include short-answer, diagramming, and analytical problem-solving sections.

**Programming Projects:** Three substantial projects are assigned across the semester, covering (1) cache simulation and performance analysis, (2) process scheduling algorithm implementation, and (3) a multithreaded systems application. Projects are submitted via the department's version-controlled submission portal and are evaluated on correctness, code quality, documentation, and performance benchmarks.

**Lab Assignments:** Six structured laboratory exercises reinforce lecture content through guided implementation tasks, including assembly language exercises, memory profiling, and I/O systems exploration. Labs are completed during scheduled sessions and submitted within one week.

**Participation & Quizzes:** Brief in-class quizzes and active engagement in lecture and lab discussions contribute to the final grade.

*Note: All submitted work is subject to Peculiar U's Academic Integrity Policy. Collaboration policies for each assessment component are detailed in the course syllabus distributed at the start of term.*
