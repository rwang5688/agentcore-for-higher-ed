### Course Description

This course provides graduate-level students with a rigorous and comprehensive foundation in the Linux operating system, covering its architecture, command-line interface, system administration principles, and scripting capabilities. Students will develop practical proficiency in configuring and managing Linux environments, with an emphasis on real-world application in engineering, research, and enterprise computing contexts. The course bridges theoretical understanding of Unix-based systems with hands-on technical competency essential for advanced study and professional practice in computer science and related disciplines.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Navigate and manage the Linux file system hierarchy, execute complex command-line operations, and utilise core utilities with confidence and precision
- Write and deploy Bash shell scripts to automate system tasks, manage processes, and perform batch data operations in a Linux environment
- Configure user accounts, file permissions, network settings, and system services in accordance with established system administration best practices
- Analyse Linux system performance, diagnose common operational issues, and apply appropriate troubleshooting methodologies to resolve software and configuration problems
- Evaluate the security implications of system configurations and implement baseline hardening techniques suitable for multi-user and networked Linux deployments

### Prerequisites

Students enrolling in COMP-11200 are expected to have completed or hold equivalent knowledge in the following:

- **COMP-70400 Operating Systems Fundamentals** or equivalent undergraduate coursework in operating systems concepts
- **COMP-60150 Introduction to Computer Architecture** or demonstrable familiarity with hardware-software interaction
- Proficiency in at least one programming or scripting language at an undergraduate level
- Graduate standing within the College of Engineering or written departmental consent

Students who are uncertain whether their background meets these requirements are encouraged to consult with the course instructor or departmental advisor prior to registration.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Lab Assignments (×6) | 30% | Biweekly hands-on laboratory exercises covering key topics including file system management, scripting, and system administration tasks |
| Midterm Examination | 20% | Written and practical examination assessing command-line proficiency, scripting logic, and conceptual understanding of Linux internals |
| System Administration Project | 25% | Individual or paired project requiring students to configure, secure, and document a fully functional Linux server environment |
| Shell Scripting Portfolio | 15% | A curated collection of original Bash scripts demonstrating automation, process management, and system monitoring competencies |
| Final Examination | 10% | Comprehensive written examination covering all course material with an emphasis on integration and applied problem-solving |

*Note: A minimum passing grade of 50% must be achieved in both the practical and written components independently. Attendance at scheduled laboratory sessions is compulsory.*
