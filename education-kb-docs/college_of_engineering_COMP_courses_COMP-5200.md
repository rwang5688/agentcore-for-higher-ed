## Course Description

### Course Description

This course provides a rigorous examination of fundamental and advanced data structures, emphasizing their design, implementation, and analysis within the context of efficient algorithm development. Students will explore structures including arrays, linked lists, trees, graphs, hash tables, heaps, and advanced variants, with attention to time and space complexity trade-offs. Practical programming assignments reinforce theoretical concepts, preparing students to select and implement appropriate data structures for complex real-world computational problems.

---

### Learning Objectives

By the end of this course, students will be able to:

- Analyze and compare the computational complexity of various data structures using Big-O, Big-Omega, and Big-Theta notation
- Design and implement core and advanced data structures, including balanced trees, priority queues, and graph representations, in a high-level programming language
- Apply appropriate data structures to solve computational problems efficiently, justifying design choices based on performance requirements
- Evaluate trade-offs between competing data structure implementations in terms of memory usage, access time, and operational overhead
- Demonstrate proficiency in debugging, testing, and documenting data structure implementations within a software engineering framework

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (5 total) | 35% |
| Midterm Examination | 20% |
| Final Examination | 25% |
| Research & Analysis Paper | 10% |
| Participation & In-Class Exercises | 10% |

**Programming Assignments:** Five structured assignments require students to implement, test, and analyse specific data structures. Submissions must include source code, complexity analysis, and written reflection.

**Midterm Examination:** A closed-book, in-person examination covering weeks one through seven, including both theoretical questions and short implementation problems.

**Final Examination:** A comprehensive closed-book examination covering all course material, with emphasis on integration of concepts and comparative analysis across data structures.

**Research & Analysis Paper:** A 2,500–3,500 word paper in which students investigate an advanced or domain-specific data structure not covered in primary course content, evaluating its applications and performance characteristics.

**Participation & In-Class Exercises:** Regular attendance and engagement are expected. Weekly in-class exercises assess comprehension of lecture material and contribute to this grade component.
