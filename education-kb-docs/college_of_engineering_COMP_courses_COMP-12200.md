## Course Description

### Course Description

COMP-12200: Learning from Data: A Machine Learning Course introduces students to the foundational principles and techniques of machine learning, with an emphasis on understanding how computational systems can learn patterns and make decisions from data. Students will explore core algorithms including supervised and unsupervised learning methods, and develop practical skills in applying these techniques to real-world datasets. This course serves as an accessible entry point into the field of machine learning for students with a basic background in computing and mathematics.

---

### Learning Objectives

By the end of this course, students will be able to:

- Explain the fundamental concepts of machine learning, including the distinction between supervised, unsupervised, and reinforcement learning paradigms.
- Apply basic machine learning algorithms such as linear regression, k-nearest neighbours, and decision trees to structured datasets.
- Evaluate model performance using standard metrics and identify common pitfalls such as overfitting and underfitting.
- Implement simple machine learning pipelines using an introductory programming environment, translating theoretical knowledge into working code.
- Interpret and communicate the results of machine learning models clearly, including a basic awareness of ethical considerations surrounding data use and algorithmic decision-making.

---

### Prerequisites

Students enrolling in COMP-12200 are expected to have completed or be concurrently enrolled in the following:

- **COMP-10100: Introduction to Programming** – foundational knowledge of programming logic, variables, loops, and functions is assumed throughout the course.
- **MATH-10200: Introduction to Statistics and Probability** – familiarity with basic statistical concepts including mean, variance, probability distributions, and hypothesis testing is essential for understanding model evaluation and algorithm design.

Students who have not completed these prerequisites or their approved equivalents should consult their academic advisor prior to enrollment. A working comfort with basic algebra is also strongly recommended.

### Assessment Methods

Student performance in COMP-12200 will be evaluated through the following components:

| Assessment | Weight | Description |
|---|---|---|
| Weekly Quizzes | 15% | Short online quizzes administered at the end of each instructional week to reinforce lecture content and assigned readings. |
| Programming Assignments (×3) | 30% | Three individual coding assignments requiring students to implement and test machine learning algorithms on provided datasets using Python. |
| Midterm Examination | 20% | A written in-class examination covering all material from the first half of the course, including conceptual and applied problem-solving questions. |
| Group Project | 25% | A collaborative project in which student teams of three to four select a real-world dataset, apply appropriate machine learning techniques, and present their findings in both a written report and a short oral presentation. |
| Final Examination | 10% | A cumulative written examination emphasising integration of course concepts and critical reflection on algorithm selection and model interpretation. |

*Note: All programming assignments must be submitted via the course portal by 11:59 PM on the stated due date. Late submissions will be penalised at a rate of 10% per day unless an extension has been approved in advance by the course instructor.*

### Required Materials

Students are required to obtain the following materials prior to the first week of class:

- **Harfield, T. & Orozco-Llanes, M.** (2022). *Patterns in the Data: An Introduction to Machine Learning for Beginners*. 3rd ed. Glenwood Academic Press. ISBN: 978-1-7742-3381-4.
- **Vanthorpe, S.** (2021). *Python for Data Thinkers: A Practical Workbook*. 2nd ed. Ridgemont Publishing. ISBN: 978-0-5519-8847-2.

The following text is recommended but not required:

- **Dunmara, C. & Fetsch, A.** (2020). *Ethics in the Age of Algorithms: Data, Society, and Responsibility*. Crestfield University Press. ISBN: 978-0-8831-0294-7.

All required readings not contained within the above texts will be made available through the course portal at no additional cost. Students will also require access to a personal computer capable of running Python 3.9 or later; free software installation guides will be provided during the first week of instruction.
