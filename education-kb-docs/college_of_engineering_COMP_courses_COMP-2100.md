## Course Description

### Course Description

This course provides a comprehensive introduction to the fundamental principles of operating systems and system-level programming, equipping students with both theoretical knowledge and practical skills essential for understanding how modern computing environments function. Topics covered include process management, memory allocation, file systems, concurrency, inter-process communication, and the role of the kernel in mediating hardware and software interaction. Students will gain hands-on experience with system programming through structured laboratory exercises and projects using low-level programming languages and command-line environments.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Describe and explain the core components and responsibilities of a modern operating system, including process scheduling, memory management, and device I/O handling
- Design and implement system-level programs in C or a comparable low-level language, demonstrating an understanding of system calls, memory allocation, and process control
- Analyze concurrency issues such as race conditions, deadlocks, and starvation, and apply appropriate synchronization mechanisms to resolve them
- Evaluate different file system architectures and articulate the trade-offs involved in storage management and data organization strategies
- Apply debugging and performance analysis tools to diagnose and resolve faults in system programs operating within a Unix/Linux environment

### Prerequisites

### Assessment Methods

Student performance will be evaluated through a combination of the following assessment components:

- **Midterm Examination (20%):** A written examination covering theoretical concepts from the first half of the course, including process management, scheduling algorithms, and memory models
- **Final Examination (25%):** A comprehensive written examination spanning all course material, with emphasis on integrating concepts across operating system subsystems
- **Programming Assignments (30%):** A series of four to five individual programming assignments requiring students to implement system-level solutions in C within a Linux environment; assignments will cover topics such as process forking, thread synchronization, and custom memory allocators
- **Systems Project (20%):** A culminating team-based project in which student groups design and partially implement a functional component of an operating system or a substantial system utility, accompanied by a written technical report
- **Participation and Laboratory Work (5%):** Active engagement in weekly laboratory sessions and in-class discussions, assessed through lab submission checkpoints and instructor observation

Late submissions will be penalized at a rate of 10% per calendar day unless a documented extension has been approved in advance by the course instructor.

### Required Materials and Textbooks

Students are expected to obtain or have access to the following materials before the first week of class:

- **Halloran, P. T., & Voss, C. M.** (4th ed.). *Foundations of Operating Systems: Principles and Practice*. Meridian Academic Press. ISBN 978-1-55342-871-4 *(Primary textbook; required)*
- **Dreyfuss, A. L.** (2nd ed.). *System Programming in C: A Practitioner's Guide*. Irongate Technical Publishing. ISBN 978-0-88214-603-9 *(Required for programming assignments)*
- **Okonkwo, R. B., & Seltzer, J.** (1st ed.). *Concurrency and Synchronization: Problems, Patterns, and Solutions*. Northfield University Press. ISBN 978-1-47218-540-3 *(Supplementary; strongly recommended)*

Access to a Unix/Linux computing environment is mandatory for all laboratory and programming work. Students may use the College of Engineering computing labs, a departmental virtual machine image provided via the course portal, or a personal machine configured with an approved Linux distribution. All required software tools are open-source and available at no cost.
