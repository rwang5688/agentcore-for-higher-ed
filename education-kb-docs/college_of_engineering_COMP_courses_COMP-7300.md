## Course Description

**COMP-7300 | Google Cloud Platform Fundamentals: Core Infrastructure**
*Credit Points: 3 | Department: Computer Science | College of Engineering*

---

This course provides a rigorous, hands-on exploration of Google Cloud Platform (GCP) core services and infrastructure, equipping students with the foundational knowledge required to design, deploy, and manage scalable cloud-based solutions in enterprise and research environments. Students will examine the architectural principles underlying GCP's compute, storage, networking, and security offerings, with an emphasis on practical application and industry-relevant workflows. The course bridges theoretical cloud computing concepts with real-world implementation strategies, preparing graduates for advanced study or professional roles in cloud architecture and infrastructure management.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a comprehensive understanding of GCP's core infrastructure services, including Compute Engine, Cloud Storage, Cloud SQL, and Virtual Private Cloud (VPC), and articulate the appropriate use cases for each
- Design and deploy scalable, fault-tolerant cloud architectures using GCP tools and services, applying best practices in resource provisioning, load balancing, and auto-scaling
- Configure and manage identity, access, and security controls within GCP environments using Cloud IAM, encryption strategies, and compliance frameworks
- Evaluate and compare cloud deployment models — including public, private, hybrid, and multi-cloud configurations — and justify architectural decisions based on cost, performance, and business requirements
- Implement monitoring, logging, and diagnostic workflows using GCP operations tools (formerly Stackdriver) to ensure system reliability, performance optimization, and compliance

### Prerequisites

Students must have completed the following, or demonstrate equivalent competency approved by the Department of Computer Science:

- **COMP-5210: Cloud Computing Principles and Architectures** or equivalent foundational cloud course
- **COMP-5140: Operating Systems and Distributed Systems** or equivalent
- **COMP-4870: Networking and Security Fundamentals** or equivalent
- Demonstrated proficiency in at least one scripting or programming language (Python, Bash, or equivalent) as assessed through prior coursework or departmental placement evaluation
- Completion of a minimum of 90 undergraduate credit points or enrollment in a recognised postgraduate program

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Laboratory Exercises (x6) | 25% | Weekly guided hands-on labs conducted within the GCP Console environment, submitted via the course portal |
| Midterm Examination | 20% | Closed-book written examination covering theoretical foundations, service architectures, and infrastructure design principles |
| Cloud Architecture Design Project | 30% | Individual or paired project requiring students to design, deploy, and document a complete GCP-based infrastructure solution addressing a defined organisational scenario |
| Final Examination | 20% | Comprehensive examination incorporating both theoretical questions and scenario-based problem solving |
| Participation & Peer Review | 5% | Active engagement in seminar discussions and structured peer review of project documentation |

**Note:** A minimum passing grade of 50% must be achieved in both the Final Examination and the Cloud Architecture Design Project independently to pass the course. Students are advised to consult the Peculiar U Academic Integrity Policy before submitting any assessed work.
