## Course Description

### Course Description

COMP-11500 provides a comprehensive and accessible introduction to programming through the Python language, designed for students with no prior coding experience. Students will explore foundational computational thinking concepts, including variables, control flow, functions, and data structures, culminating in the development of small-scale functional programs. This course serves as a gateway to more advanced study in computer science and software development within the College of Engineering.

### Learning Objectives

By the end of this course, students will be able to:

- Write, execute, and debug basic Python programs using appropriate syntax, data types, and control structures
- Apply fundamental programming concepts such as loops, conditionals, and functions to solve well-defined computational problems
- Demonstrate an understanding of core data structures, including lists, dictionaries, and tuples, and select appropriate structures for a given task
- Decompose complex problems into logical, manageable steps using algorithmic thinking and pseudocode planning
- Produce readable, well-commented code that adheres to standard Python conventions and basic software design principles

### Prerequisites

Despite its introductory subject matter, COMP-11500 is a 375-level course and assumes a degree of academic and analytical maturity. Students are expected to have completed the following:

- **MATH-20200** – Discrete Mathematics or equivalent
- **COMP-10100** – Computational Thinking and Digital Literacy
- **COMP-20400** – Foundations of Computer Science I

Students who have not completed the above prerequisites but believe they have equivalent preparation are encouraged to speak with the course coordinator, Professor Aubree Marschel, to discuss a prerequisite waiver.

### Assessment Methods

| Assessment Component | Weight |
|---|---|
| Weekly Programming Exercises (10 submissions) | 25% |
| Midterm Examination (practical coding test) | 20% |
| Lab Participation and In-Class Exercises | 10% |
| Project 1 – Mini Application (solo) | 15% |
| Project 2 – Capstone Programming Portfolio (pair or solo) | 20% |
| Final Examination (written and practical components) | 10% |

**Programming Exercises** are submitted weekly via the university's online coding environment and are auto-graded with instructor review. **Projects** are evaluated using a detailed rubric covering functionality, code quality, documentation, and originality. The **Capstone Portfolio** requires students to submit three functional Python programs of increasing complexity, accompanied by a written reflection on design choices and challenges encountered.

Students are expected to obtain the following materials before the first week of class:

Students will also require access to **Python 3.11 or later**, which is free to download at python.org, and are encouraged to install **Visual Studio Code** as their primary development environment. Detailed setup instructions are provided in the course orientation module.
