## Course Description

### Course Description

DATA-3200: Open Source Tools for Data Science provides students with comprehensive, hands-on experience using industry-standard open source technologies for data acquisition, manipulation, analysis, and visualization. Students will develop practical proficiency in widely adopted frameworks and libraries within the Python and R ecosystems, preparing them for professional and research environments that rely on reproducible, community-driven software. Emphasis is placed on workflow integration, collaborative development practices, and the application of open source tools to real-world data science challenges.

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate proficiency in core open source data science libraries, including pandas, NumPy, scikit-learn, ggplot2, and tidyverse, applying them effectively to structured and unstructured datasets
- Design and implement reproducible data science workflows using version control systems such as Git and collaborative platforms including GitHub and GitLab
- Construct meaningful data visualizations and exploratory analyses using tools such as Matplotlib, Seaborn, and Plotly to communicate findings to both technical and non-technical audiences
- Evaluate and select appropriate open source tools for a given analytical task, demonstrating awareness of community support, licensing considerations, and software sustainability
- Deploy and manage isolated computational environments using tools such as conda, Docker, and Jupyter, ensuring consistency and reproducibility across collaborative projects

### Prerequisites

Students enrolling in DATA-3200 must have successfully completed the following courses or demonstrate equivalent competency:

- **DATA-1100: Introduction to Data Science** or **CS-1150: Introduction to Programming** — foundational programming literacy and familiarity with data structures is assumed
- **DATA-2210: Data Wrangling and Exploratory Analysis** — prior exposure to tabular data manipulation and basic statistical summaries is required
- **MATH-2010: Probability and Statistics for Engineers** or equivalent — students are expected to understand descriptive statistics, probability distributions, and basic inferential methods
- Familiarity with command-line interfaces (Linux/Unix shell) is strongly recommended; students lacking this background are encouraged to complete the department's self-paced shell literacy module prior to the first week of instruction

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Weekly Lab Assignments | 30% | Short, applied exercises completed in Jupyter Notebooks, submitted via GitHub Classroom each week |
| Midterm Examination | 15% | Written and practical examination covering core library usage, environment management, and workflow concepts |
| Tool Evaluation Report | 15% | A 1,500–2,000 word written report in which students critically assess an open source data science tool not covered in lectures, evaluating its functionality, community health, and appropriate use cases |
| Collaborative Project | 30% | A team-based project (groups of 3–4) requiring students to define a data question, build a full analytical pipeline using exclusively open source tools, version the work on GitHub, and present findings to the class |
| Participation and Peer Review | 10% | Active engagement in lab sessions and structured peer review of teammates' code using pull requests and documented feedback |

All submissions must follow reproducibility standards outlined in the course style guide. Late submissions will be penalized 10% per calendar day unless prior arrangements have been made with the instructional team.
