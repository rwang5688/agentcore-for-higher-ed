## Course Description

### Course Description

COMP-13100: Massively Parallel Computing provides an advanced examination of the architectural principles, programming paradigms, and algorithmic strategies underlying large-scale parallel computing systems. Students will explore the design and implementation of high-performance parallel applications across distributed memory, shared memory, and hybrid computing environments, including modern GPU and cluster-based infrastructures. Emphasis is placed on both the theoretical foundations of parallel computation and the practical skills required to engineer efficient, scalable software solutions for computationally intensive problems.

---

### Learning Objectives

By the end of this course, students will be able to:

- Analyse and compare the principal architectures of massively parallel computing systems, including SIMD, MIMD, distributed memory, and shared memory models, evaluating their relative strengths and limitations.
- Design and implement parallel algorithms using industry-standard frameworks and APIs, including MPI, OpenMP, and CUDA, demonstrating proficiency in task decomposition, synchronisation, and communication optimisation.
- Apply formal performance analysis techniques — including Amdahl's Law, Gustafson's Law, and roofline modelling — to evaluate and optimise the scalability and efficiency of parallel programs.
- Identify and resolve common parallelism hazards such as race conditions, deadlocks, load imbalance, and communication bottlenecks within complex multi-threaded and distributed environments.
- Evaluate emerging trends and research directions in massively parallel computing, including heterogeneous computing, exascale architectures, and fault-tolerant parallel system design.

---

### Prerequisites

Students must have successfully completed the following prior to enrolment:

- **COMP-11200: Data Structures and Algorithms** — foundational knowledge of algorithmic complexity and data organisation is essential for designing efficient parallel solutions.
- **COMP-12150: Computer Architecture and Organisation** — understanding of processor design, memory hierarchies, and instruction-level parallelism is required.
- **COMP-12300: Operating Systems** — familiarity with process management, threading models, synchronisation primitives, and memory management is assumed throughout this course.
- **COMP-12450: Concurrent and Distributed Systems** — prior exposure to concurrency concepts, inter-process communication, and distributed system fundamentals is strongly recommended.
- Proficiency in at least one systems-level programming language (C or C++ strongly preferred); students without this background are advised to consult the instructor prior to enrolment.

### Assessment Methods

Student performance will be evaluated through the following components:

| Component | Weight | Description |
|---|---|---|
| Programming Assignments (×4) | 40% | Four progressively challenging implementation projects requiring students to develop, profile, and optimise parallel applications using MPI, OpenMP, and CUDA on the university's high-performance computing cluster. |
| Midterm Examination | 15% | A written examination covering parallel architecture theory, algorithmic analysis, and performance modelling completed during scheduled class time. |
| Final Examination | 20% | A comprehensive written examination assessing mastery of all course content, with emphasis on integrating concepts across multiple parallel computing paradigms. |
| Research Paper | 15% | An individual written report (3,000–4,500 words) critically analysing a current topic or recent advancement in massively parallel computing, drawing on peer-reviewed literature. |
| Group Scalability Project | 10% | A team-based capstone project in which student groups design, implement, benchmark, and present a parallel solution to a real-world high-performance computing problem, with final deliverables including a technical report and live demonstration. |

*All programming assignments must be submitted through the university's course management portal. Late submissions will incur a penalty of 10% per calendar day unless a formal extension has been approved by the course coordinator in advance.*
