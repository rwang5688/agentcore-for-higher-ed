### Course Description

This course provides a rigorous introduction to the principles and practical techniques of multicore programming, equipping students with the foundational skills necessary to design, implement, and analyse concurrent software systems. Topics covered include thread management, synchronisation primitives, parallel algorithm design, and the challenges of shared-memory architectures across multiple processing cores. Students will engage with real-world programming tasks that highlight both the performance opportunities and the correctness pitfalls inherent in concurrent and parallel computing environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Explain the fundamental concepts of concurrency and parallelism, including thread lifecycle, context switching, and the distinctions between task-level and data-level parallelism.
- Apply synchronisation mechanisms — including mutexes, semaphores, condition variables, and barriers — to construct correct and efficient concurrent programs.
- Identify and resolve common concurrency hazards such as race conditions, deadlocks, livelocks, and priority inversion in multicore software systems.
- Design and implement parallel algorithms using established programming frameworks and libraries, evaluating their performance characteristics using appropriate profiling and benchmarking tools.
- Critically assess the trade-offs between parallelism, scalability, and software correctness when engineering solutions for multicore hardware architectures.

### Assessment Methods

Student performance in COMP-13500 will be evaluated through a combination of the following assessment components:

| Assessment Component | Weight | Description |
|---|---|---|
| Programming Assignments (×4) | 40% | A series of four progressively complex coding assignments requiring students to implement concurrent and parallel solutions to defined computational problems, with emphasis on correctness and performance. |
| Midterm Examination | 20% | A closed-book written examination assessing theoretical understanding of concurrency concepts, synchronisation models, and parallel algorithm analysis covered in the first half of the course. |
| Laboratory Practicals | 15% | Weekly guided lab sessions in which students apply lecture material in supervised, structured programming exercises on multicore hardware. Participation and submitted lab reports are assessed. |
| Final Project | 20% | A team-based project (groups of two to three students) requiring the design, implementation, profiling, and written documentation of a non-trivial parallel application. A brief oral defence is required upon submission. |
| Final Examination | 5% | A comprehensive closed-book examination administered during the official examination period, covering all course material. |

*Note: Students must achieve a passing grade on both the final examination and the programming assignment portfolio to pass the course overall.*
