## Course Description

### Course Description

COMP-13000: Machine Structures provides a foundational examination of the interface between hardware and software, exploring how high-level programming constructs are translated into machine-level instructions and executed by underlying computer hardware. Students will investigate the organization and architecture of modern computing systems, including processor design, memory hierarchies, and input/output mechanisms. This course establishes the essential conceptual bridge between abstract programming and the physical machines on which software operates.

### Learning Objectives

By the end of this course, students will be able to:

- Describe the fundamental components of a computer system, including the CPU, memory, storage, and I/O subsystems, and explain how these components interact during program execution
- Translate and analyse programs written in a high-level language into assembly language and binary machine code representations
- Explain how data is represented at the machine level, including integer and floating-point encodings, bitwise operations, and number system conversions
- Apply knowledge of the memory hierarchy — including cache, RAM, and virtual memory — to reason about program performance and resource management
- Demonstrate a working understanding of the instruction set architecture (ISA) and the fetch-decode-execute cycle as the basis for program control flow

### Prerequisites

Students must have successfully completed the following prior to enrolling in COMP-13000:

- **COMP-10100: Introduction to Programming** or demonstrated equivalent proficiency in a structured programming language
- **MATH-10200: Discrete Mathematics for Computing** or equivalent, covering basic logic, number systems, and Boolean algebra
- A minimum cumulative GPA of 2.0 is recommended; students without prior programming experience are strongly advised to consult with their academic advisor before registering

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Midterm Examination | 20% | In-class written and short-answer exam covering data representation, number systems, and ISA fundamentals |
| Final Examination | 25% | Comprehensive written examination spanning all course topics, including architecture, memory, and assembly programming |
| Assembly Programming Projects (×3) | 30% | A series of three progressively complex programming assignments requiring students to write, debug, and optimise assembly language code for a specified ISA |
| Laboratory Exercises | 15% | Weekly structured lab sessions in which students apply lecture concepts using simulation and hardware emulation tools |
| Participation & In-Class Quizzes | 10% | Short unannounced quizzes and active participation in discussion sections to reinforce foundational concepts |

*Note: Students must achieve a passing grade on the final examination to pass the course overall. Late submissions are subject to a 10% per day deduction unless prior arrangements have been made with the course instructor.*
