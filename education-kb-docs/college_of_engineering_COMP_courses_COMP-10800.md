### Course Description

This course provides a comprehensive introduction to the design, programming, and analysis of embedded systems — dedicated computing devices that operate within larger mechanical or electronic systems. Students will explore the intersection of hardware and software, examining how microcontrollers, real-time operating systems, and low-level programming techniques are applied to solve practical engineering problems. Emphasis is placed on developing hands-on proficiency with embedded hardware platforms and understanding the constraints unique to resource-limited computing environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement firmware for microcontroller-based systems using C and assembly language, demonstrating an understanding of memory management, interrupt handling, and I/O interfacing.
- Analyze the timing, power, and resource constraints inherent to embedded computing environments and apply appropriate design strategies to address them.
- Interface embedded processors with external peripherals — including sensors, actuators, and communication modules — using standard protocols such as I²C, SPI, and UART.
- Evaluate the role and structure of real-time operating systems (RTOS) and apply scheduling principles to ensure deterministic system behaviour.
- Develop, test, and debug embedded software projects using professional toolchains, simulation environments, and hardware debugging instruments.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Laboratory Assignments (x6) | 30% | Hands-on embedded programming and hardware interfacing tasks completed during scheduled lab sessions |
| Midterm Examination | 20% | Written examination covering theory, architecture, and low-level programming concepts |
| Design Project – Milestone Submissions | 20% | Staged submissions documenting the design, implementation, and testing of an original embedded system prototype |
| Final Design Project & Demonstration | 20% | Live demonstration and technical report for the completed embedded system project |
| Final Examination | 10% | Comprehensive written examination covering all course material |

**Laboratory Participation Note:** Attendance at a minimum of five of the six scheduled laboratory sessions is mandatory. Students who miss more than one lab without an approved accommodation may be ineligible to submit the final design project.
