## Course Description

### Course Description

COMP-13300: Media Programming introduces students to the foundational principles of programming within the context of digital media creation and manipulation. Students will explore how computational techniques are applied to audio, video, image, and interactive media, developing practical skills in writing code that drives modern media applications. This course bridges the gap between computer science fundamentals and real-world media technologies, equipping students with the tools to design and implement media-driven software solutions.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a working understanding of programming constructs—including variables, loops, conditionals, and functions—as applied to media processing tasks
- Write and debug programs that manipulate digital media objects such as images, audio files, and video streams
- Identify and apply appropriate data structures and algorithms suited to the demands of media-intensive applications
- Analyze and evaluate the performance characteristics of media programming solutions in terms of efficiency and scalability
- Design and implement a small-scale interactive media application that integrates multiple media types using an industry-relevant programming environment

---

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- **COMP-10100: Introduction to Computing and Digital Systems** — Foundational knowledge of computer hardware, software, and basic digital concepts
- **COMP-11200: Principles of Programming I** — Introductory programming experience in a high-level language, including variables, control flow, and basic input/output

A minimum grade of **C** or better is required in all prerequisite courses. Students who have not completed these prerequisites must obtain written departmental approval before registering.

---

### Assessment Methods

Student performance will be evaluated through a combination of the following:

- **Programming Assignments (35%)** — A series of five to seven incremental coding assignments in which students write programs to process, generate, and manipulate various media types. Assignments are graded on correctness, code clarity, and adherence to course style guidelines.
- **Midterm Examination (20%)** — A written and practical examination covering core programming concepts, media data representations, and problem-solving strategies introduced in the first half of the course.
- **Lab Participation and Weekly Exercises (15%)** — Structured in-lab activities completed during scheduled lab sessions, assessing hands-on proficiency and active engagement with course material.
- **Final Project (25%)** — A culminating individual or paired project requiring students to design, implement, and present an original media application. A written technical report and live demonstration are required.
- **Final Examination (5%)** — A cumulative practical exam assessing students' ability to read, interpret, and modify provided media programming code under timed conditions.
