### Course Description

This course provides students with a foundational and practical understanding of the processes involved in acquiring, transforming, and preparing raw data for analysis. Students will explore a range of data sources — including flat files, web APIs, and relational databases — and develop systematic approaches to identifying and resolving common data quality issues such as missing values, inconsistent formatting, and structural irregularities. Emphasis is placed on reproducibility and the development of clean, well-documented data workflows that meet professional standards in data science practice.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Retrieve and import data from diverse sources, including CSV and JSON files, REST APIs, and basic SQL database queries, using industry-standard programming tools.
- Identify and diagnose common data quality problems, including duplicate records, outliers, missing entries, and inconsistent data types, applying appropriate remediation strategies.
- Apply data reshaping and transformation techniques — such as filtering, merging, pivoting, and aggregating — to convert raw datasets into analysis-ready formats.
- Design and implement reproducible data cleaning pipelines that are clearly documented, version-controlled, and transferable across projects.
- Critically evaluate the ethical and practical implications of data collection methods and cleaning decisions, recognising how such choices can introduce bias or affect downstream analysis.

### Prerequisites

Students must have successfully completed the following prior to enrolling in DATA-2200:

- **COMP-1100: Introduction to Programming** or equivalent demonstrated proficiency in a scripting language (Python or R preferred)
- **DATA-1100: Foundations of Data Science** or **MATH-1150: Introduction to Statistics**

Students without formal prerequisite completion may seek instructor permission by submitting a portfolio of relevant prior work to the course coordinator.

### Assessment Methods

| Assessment Component | Weight | Description |
|---|---|---|
| Lab Assignments (×5) | 30% | Weekly hands-on coding exercises focused on specific data acquisition and cleaning techniques |
| Midterm Examination | 20% | Written and practical examination covering data formats, quality diagnostics, and transformation concepts |
| Data Cleaning Project | 30% | Individual project requiring students to locate a real-world messy dataset, document its quality issues, implement a full cleaning pipeline, and submit a reproducibility report |
| Final Examination | 15% | Comprehensive written examination assessing theoretical knowledge and applied reasoning |
| Participation & Peer Review | 5% | Structured peer review of a classmate's data cleaning project, with written evaluative feedback |

All lab assignments must be submitted via the course repository platform with accompanying documentation. Late submissions incur a penalty of 10% per calendar day unless a formal extension has been granted.
