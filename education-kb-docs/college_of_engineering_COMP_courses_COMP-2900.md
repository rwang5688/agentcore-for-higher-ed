### Course Description

This course introduces students to the fundamentals of programming in the C language, with an emphasis on developing a rigorous understanding of low-level computing concepts including memory management, pointers, and structured programming techniques. Students will gain hands-on experience writing, compiling, and debugging C programs within a Unix/Linux environment, building a strong foundation for further study in systems programming and software development. By the end of the course, students will be equipped to design and implement well-structured programs that demonstrate efficient use of core C constructs and standard libraries.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- **Understand and apply** core C programming constructs, including variables, data types, control flow structures, functions, and arrays, to solve well-defined computational problems.
- **Demonstrate proficiency** in the use of pointers and dynamic memory allocation, including the correct use of `malloc`, `calloc`, `realloc`, and `free`, while avoiding common memory-related errors such as leaks and dangling references.
- **Write, compile, and debug** C programs using standard development tools including `gcc`, `make`, and `gdb` within a command-line environment.
- **Design modular programs** through the use of header files, multi-file compilation, and structured decomposition of problems into reusable functions and logical program units.
- **Apply fundamental principles** of file I/O and string manipulation using the C standard library, and interpret and respond appropriately to runtime errors and edge cases.

### Prerequisites

Students must have successfully completed the following prior to enrolling in COMP-2900:

- **COMP-1100: Introduction to Computing and Digital Systems** or equivalent, with a minimum grade of C
- **COMP-1200: Foundations of Programming** (any language) or equivalent, with a minimum grade of C
- Co-requisite or prior completion of **MATH-1050: Discrete Structures for Computer Science** is strongly recommended

Students with no prior programming experience are encouraged to consult their academic advisor before enrolling, as the course proceeds at a pace that assumes basic familiarity with programming logic, variables, and control flow.

| Component | Weight | Description |
|---|---|---|
| Programming Assignments (×6) | 40% | Six progressive coding assignments covering key course topics, submitted via the course portal |
| Midterm Examination | 20% | Written and practical examination covering Weeks 1–7 material |
| Final Examination | 25% | Comprehensive written and practical examination |
| Lab Participation | 10% | Attendance and completion of weekly supervised lab exercises |
| Debugging Challenge | 5% | In-class timed debugging exercise assessing practical diagnostic skills |

**Programming Assignments** are submitted electronically and evaluated on correctness, code quality, appropriate use of comments, and adherence to style guidelines outlined in the course coding standard. Late submissions will incur a penalty of 10% per day unless a formal extension has been approved in advance.

**Examinations** are conducted in-person under closed-book conditions. Students are permitted one double-sided handwritten reference sheet during both the midterm and final examinations.
