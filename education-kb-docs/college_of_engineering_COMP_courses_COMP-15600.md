## Course Description

### Course Description

COMP-15600 provides an advanced examination of data representation techniques and structures using the Python programming language, with emphasis on the design, analysis, and implementation of complex data models suitable for large-scale computational applications. Students will explore how Python's native and extended data constructs can be leveraged to optimize memory usage, processing efficiency, and interoperability across diverse computing environments. This course bridges theoretical foundations in data structures with practical, applied programming challenges encountered in professional and research settings.

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement advanced Python data structures, including custom classes, nested collections, and memory-efficient representations appropriate for high-performance applications
- Analyze the computational complexity and memory trade-offs of competing data representation strategies and justify design choices in the context of real-world constraints
- Apply serialization, deserialization, and data interchange formats — including JSON, XML, Protocol Buffers, and binary encoding schemes — to facilitate data persistence and cross-platform communication
- Construct and manipulate hierarchical, graph-based, and multidimensional data representations using Python libraries such as NumPy, Pandas, and NetworkX
- Critically evaluate and refactor existing Python codebases to improve data representation quality, readability, and scalability in accordance with industry best practices

### Prerequisites

Students enrolling in COMP-15600 must have successfully completed the following or demonstrate equivalent competency:

- **COMP-42200: Data Structures and Algorithms** — foundational understanding of arrays, linked lists, trees, hash tables, and algorithmic complexity is assumed
- **COMP-50100: Intermediate Python Programming** — proficiency in object-oriented Python, including class design, inheritance, and standard library usage, is required
- **COMP-51800: Introduction to Database Systems** — familiarity with relational and non-relational data models is expected at this level
- Graduate standing within the College of Engineering or written consent of the supervising instructor

### Assessment Methods

Student performance will be evaluated through a combination of the following components:

- **Programming Assignments (35%)** — Five structured coding assignments distributed throughout the semester, each targeting a specific domain of data representation. Assignments require submission of well-documented, tested Python code along with a brief written rationale justifying design decisions.
- **Midterm Examination (20%)** — A closed-book written and practical examination covering theoretical foundations, complexity analysis, and short Python implementation problems completed during a scheduled class period.
- **Research and Implementation Project (30%)** — A substantial individual or paired project in which students identify a domain-specific data representation challenge, design a Python-based solution, implement and benchmark the solution, and present findings in both a written report (minimum 3,000 words) and a live in-class demonstration during the final two weeks of the semester.
- **Final Examination (15%)** — A comprehensive examination encompassing all course material, including application-level questions requiring students to select and defend data representation strategies under defined constraints.

Grading follows Peculiar University's standard graduate-level scale. Students are expected to adhere strictly to the university's academic integrity policy; all submitted code will be processed through automated similarity detection tools.
