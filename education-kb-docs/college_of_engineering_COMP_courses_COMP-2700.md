## Course Description

### Course Description

This course provides a comprehensive introduction to the design, development, and deployment of mobile applications for contemporary platforms, with emphasis on both Android and iOS environments. Students will explore the full mobile development lifecycle, including user interface design, data management, and integration with device hardware and external APIs. Through hands-on project work, students develop practical proficiency in industry-standard frameworks and tools used in professional mobile software development.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement functional mobile applications using current cross-platform or native development frameworks, applying sound software engineering principles
- Construct responsive and accessible user interfaces that conform to established mobile platform design guidelines and usability standards
- Integrate mobile applications with external data sources, RESTful APIs, and local storage solutions to support dynamic, data-driven functionality
- Apply debugging, testing, and performance optimization techniques specific to mobile environments to produce stable and efficient applications
- Evaluate and address key considerations in mobile application deployment, including platform submission requirements, versioning, and basic security practices

### Prerequisites

Students enrolling in COMP-2700 must have successfully completed the following:

- **COMP-1200: Introduction to Programming** or demonstrated equivalent proficiency
- **COMP-1350: Object-Oriented Programming Fundamentals**
- **COMP-1420: Data Structures and Algorithms I** (may be taken concurrently with instructor approval)

Students are also expected to have working familiarity with at least one object-oriented programming language such as Java, Kotlin, Swift, or Python prior to enrollment.

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (4–5 individual projects) | 35% |
| Midterm Examination | 15% |
| Lab Participation and Exercises | 10% |
| Group Mobile Application Project | 25% |
| Final Examination | 15% |

**Programming Assignments** consist of structured coding tasks designed to reinforce lecture content, covering topics such as UI layout, navigation patterns, and API consumption. The **Group Mobile Application Project** requires student teams of three to four members to conceive, design, build, and present a fully functional mobile application addressing a real-world problem. A written project report and live demonstration are required components of the final submission. Both examinations are closed-book and assess conceptual understanding, design reasoning, and code comprehension.

### Required Materials

- Hargrove, T. & Soledad, P. (2022). *Mobile Development in Practice: Cross-Platform Principles and Patterns* (3rd ed.). Meridian Technical Press.
- Aldrich, C. (2021). *Interface Design for Mobile Systems: A Human-Centered Approach*. Crestline Academic Publishing.
- Wentworth, D. & Nakai, R. (2023). *Applied Android and iOS Development: From Concept to Deployment*. Northbridge Computing Series.

Students will additionally require access to a personal computer capable of running Android Studio or Xcode (or both), as well as a registered developer account for the relevant platform(s). A compatible physical mobile device is strongly recommended for testing purposes, though emulator-based development is supported. All required software is available free of charge through the manufacturer and through Peculiar University's software licensing portal.
