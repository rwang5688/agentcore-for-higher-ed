## Course Description

### Course Description

COMP-0200: Advanced Data Structures provides an in-depth exploration of complex data organization techniques and their practical applications in software development and algorithm design. Students will examine the theoretical foundations and implementation strategies of advanced structures including balanced trees, heaps, hash tables, graphs, and tries, with emphasis on analyzing time and space complexity. This course bridges foundational programming knowledge with the rigorous computational thinking required for upper-division computer science study.

---

### Learning Objectives

By the end of this course, students will be able to:

- Design, implement, and evaluate advanced data structures including AVL trees, red-black trees, B-trees, priority queues, and directed and undirected graphs in a high-level programming language
- Analyze the time and space complexity of data structure operations using Big-O, Big-Theta, and Big-Omega notation to justify design decisions in software contexts
- Select and apply appropriate data structures to solve complex computational problems, demonstrating an understanding of the trade-offs between efficiency, memory usage, and implementation complexity
- Implement and trace fundamental graph algorithms including depth-first search, breadth-first search, Dijkstra's algorithm, and minimum spanning tree algorithms
- Communicate technical solutions clearly through written documentation and code commentary, demonstrating professional standards in software design and analysis

---

### Prerequisites

Students must have successfully completed the following before enrolling in COMP-0200:

- **COMP-0101: Introduction to Programming** or equivalent, with a minimum grade of C
- **COMP-0150: Foundations of Data Structures** or equivalent, demonstrating familiarity with arrays, linked lists, stacks, and queues
- **MATH-0110: Discrete Mathematics**, covering basic logic, set theory, and introductory proof techniques

Students without the listed prerequisites must obtain written instructor approval prior to registration.

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (4–5 over the semester) | 35% |
| Midterm Examination | 20% |
| Final Examination | 25% |
| Algorithm Analysis Paper | 10% |
| Participation & In-Class Exercises | 10% |

**Programming Assignments** require students to implement and test data structures and algorithms in a language approved by the instructor (typically Java, Python, or C++). Assignments are submitted through the university's online code repository portal and are evaluated on correctness, efficiency, and code quality.

**The Algorithm Analysis Paper** (approximately 1,500–2,000 words) asks students to investigate a real-world application of an advanced data structure, analyze its computational properties, and propose optimizations or alternatives. Papers are due in Week 12 and must follow the department's technical writing guidelines.

**Examinations** are closed-book and held in-person. Students may bring one hand-written reference sheet (8.5" × 11", both sides) to each exam. Exams include a combination of multiple-choice, short-answer, and algorithm tracing questions.
