### Course Description

This course provides an in-depth exploration of fundamental and advanced data structures as implemented in the Python programming language, with emphasis on their practical application in data science workflows. Students will examine the design, analysis, and performance characteristics of structures including lists, stacks, queues, trees, graphs, hash tables, and heaps, developing the ability to select and implement appropriate structures for real-world data problems. The course bridges theoretical computer science foundations with applied data science practice, equipping students to write efficient, scalable Python code for complex analytical tasks.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement core data structures in Python, including linked lists, binary trees, hash maps, and priority queues, demonstrating a clear understanding of their underlying logic and memory management.
- Analyze the time and space complexity of common data structure operations using Big-O notation, and evaluate trade-offs when selecting structures for specific computational problems.
- Apply Python-native data structures and libraries — including collections, heapq, and itertools — to efficiently process, organize, and transform large datasets typical of data science applications.
- Develop and debug Python programs that integrate multiple data structures to solve multi-step problems, demonstrating proficiency in modular, readable, and well-documented code.
- Critically evaluate algorithmic performance through empirical testing and profiling, interpreting results to justify data structure and algorithm choices in the context of data-intensive applications.

### Prerequisites

Students must have successfully completed the following before enrolling in DATA-3600:

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (5 assignments) | 35% |
| Midterm Examination | 20% |
| Laboratory Exercises & Participation | 10% |
| Data Structures Implementation Project | 25% |
| Final Examination | 10% |

**Programming Assignments:** Five structured assignments distributed across the semester, each requiring the implementation, testing, and written analysis of specific data structures and associated algorithms in Python. Assignments must be submitted via the university's code repository portal with full documentation and unit tests.

**Midterm Examination:** A written and practical examination covering data structure theory, complexity analysis, and in-class Python implementation tasks completed under timed conditions.

**Laboratory Exercises & Participation:** Weekly laboratory sessions involve guided coding exercises reinforcing lecture content. Active participation and timely submission of lab worksheets contribute to this component.

**Data Structures Implementation Project:** A substantial capstone project completed individually or in pairs, in which students design and build a Python-based data management system addressing a provided or approved real-world data science scenario. A written technical report and live code demonstration are required.

**Final Examination:** A comprehensive written examination covering all course material, with particular emphasis on cumulative understanding of data structure selection, complexity trade-offs, and Python implementation best practices.
