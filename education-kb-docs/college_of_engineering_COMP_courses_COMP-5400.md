## Course Description

### Course Description

This course provides an in-depth examination of fundamental and advanced data structures and algorithms essential to efficient software design and computational problem-solving. Students will explore the theoretical underpinnings and practical implementations of structures including trees, graphs, heaps, and hash tables, alongside classic and contemporary algorithmic strategies such as dynamic programming, greedy methods, and graph traversal. Emphasis is placed on algorithm analysis, complexity theory, and the application of these concepts to real-world engineering challenges.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Analyze the time and space complexity of algorithms using asymptotic notation (Big-O, Big-Θ, Big-Ω) and apply this analysis to evaluate and compare algorithmic efficiency
- Design, implement, and manipulate core data structures — including linked lists, binary search trees, balanced trees, heaps, graphs, and hash tables — selecting appropriate structures for given problem contexts
- Apply advanced algorithmic paradigms, including divide-and-conquer, dynamic programming, greedy algorithms, and backtracking, to solve complex computational problems
- Formulate and justify correctness proofs for algorithms and data structure operations using formal reasoning and mathematical induction
- Critically evaluate trade-offs in algorithm and data structure selection with respect to performance, scalability, and the constraints of practical software systems

### Prerequisites

Students enrolling in COMP-5400 must have successfully completed the following courses or obtained instructor approval:

- **COMP-3100: Introduction to Programming and Software Design** — foundational programming competency in at least one high-level language (e.g., Java, Python, or C++)
- **COMP-3250: Discrete Mathematics for Computer Science** — including coverage of logic, set theory, mathematical induction, and combinatorics
- **COMP-4110: Foundations of Computing and Computational Theory** — introductory exposure to algorithm design and basic complexity concepts
- **MATH-3015: Linear Algebra and Applied Mathematics** — recommended for students pursuing the advanced algorithm analysis components of the course

Students are expected to have a working proficiency in at least one object-oriented or systems programming language prior to enrollment.

### Assessment Methods

| Component | Weight |
|---|---|
| Midterm Examination | 20% |
| Final Examination | 25% |
| Programming Assignments (×5) | 30% |
| Algorithm Analysis Problem Sets (×4) | 15% |
| Research and Implementation Project | 10% |

**Midterm and Final Examinations:** Both examinations are closed-book and assess students' theoretical understanding of data structures, algorithm design, and complexity analysis. The final examination is cumulative and includes both written derivation problems and short-answer conceptual questions.

**Programming Assignments:** Five structured assignments require students to implement, test, and benchmark data structures and algorithms in a designated programming language. Assignments are submitted via the course repository system and are evaluated on correctness, efficiency, and code quality.

**Algorithm Analysis Problem Sets:** Four written problem sets focus on formal complexity analysis, recurrence relations, and proof of algorithm correctness. Students are expected to demonstrate rigorous mathematical reasoning throughout.

**Research and Implementation Project:** Completed individually or in pairs, this capstone project requires students to identify a real-world computational problem, select and justify appropriate data structures and algorithms, implement a working solution, and submit a formal written report alongside a live demonstration to the instructional team.
