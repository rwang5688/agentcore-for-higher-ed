## Course Description

**COMP-15200 | Python | 4 Credit Points**
*Department of Computer Science — College of Engineering*

---

This course provides a comprehensive introduction to programming in Python, covering foundational syntax, data structures, and object-oriented design principles within the context of real-world software development. Students will develop practical skills in writing clean, efficient, and well-documented Python code while exploring the language's extensive standard library and ecosystem. Emphasis is placed on problem-solving methodology and computational thinking as applied through Python's versatile and widely-adopted programming paradigm.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Write syntactically correct and logically sound Python programs utilizing core language features including control flow, functions, modules, and exception handling
- Design and implement solutions using Python's built-in data structures, including lists, dictionaries, tuples, and sets, selecting appropriate structures based on problem requirements
- Apply object-oriented programming principles — including encapsulation, inheritance, and polymorphism — to construct modular and maintainable Python applications
- Utilize standard Python libraries and third-party packages to perform tasks such as file I/O, data manipulation, and basic scripting automation
- Debug, test, and document Python programs effectively using industry-standard practices, including unit testing frameworks and code style guidelines (PEP 8)

---

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- **COMP-10100: Introduction to Computer Science** or equivalent foundational computing coursework
- **COMP-12200: Programming Fundamentals I** — introductory programming experience in any language is strongly recommended
- A grade of **C or higher** in all prerequisite courses is required

Students without formal programming experience who nonetheless demonstrate proficiency through placement assessment may petition the Department of Computer Science for prerequisite waiver consideration.

---

### Assessment Methods

Student performance will be evaluated through the following components:

| Component | Weight |
|---|---|
| Programming Assignments (6–8 individual projects) | 35% |
| Midterm Examination | 20% |
| Final Examination | 25% |
| Laboratory Exercises & Weekly Coding Challenges | 10% |
| Capstone Programming Project | 10% |

**Programming Assignments** are submitted via the department's online code evaluation platform and are assessed on correctness, efficiency, and adherence to style standards. The **Capstone Programming Project**, completed individually or in pairs (at instructor discretion), requires students to design, implement, and present a Python application that demonstrates mastery of course concepts. **Examinations** include both written conceptual questions and live coding components administered in a proctored lab environment.
