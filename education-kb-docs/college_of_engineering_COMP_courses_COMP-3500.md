## Course Description

### Course Description

COMP-3500: Computer Graphics introduces students to the fundamental principles and techniques underlying the creation, manipulation, and rendering of two-dimensional and three-dimensional graphical content using computational methods. Topics covered include geometric transformations, rasterization, illumination models, shading algorithms, texture mapping, and an introduction to the graphics pipeline as implemented in modern hardware. Students will gain both theoretical grounding and practical experience through programming projects utilizing a contemporary graphics API.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Explain and apply fundamental 2D and 3D geometric transformations, including translation, rotation, scaling, and projection, within a scene representation framework
- Implement core rendering techniques such as ray casting, rasterization, Phong shading, and texture mapping using a graphics programming library
- Analyze and describe the stages of the modern programmable graphics pipeline, including the roles of vertex and fragment shaders
- Design and develop interactive graphical applications that demonstrate competency in scene management, camera control, and lighting models
- Evaluate trade-offs between rendering quality and computational performance, applying appropriate optimization strategies for real-time and offline graphics contexts

### Prerequisites

Students must have successfully completed the following before enrolling in COMP-3500:

- **COMP-2200: Data Structures and Algorithms** — foundational understanding of algorithmic complexity and data organization is essential for efficient graphics programming
- **COMP-2310: Object-Oriented Software Design** — proficiency in an object-oriented language (preferably C++ or Java) is required for graphics API work
- **MATH-2150: Linear Algebra** — matrix operations, vector spaces, and linear transformations form the mathematical backbone of graphics computation
- **MATH-2050: Calculus II** — familiarity with multivariable concepts and parametric representations is assumed throughout the course

Students who have not completed MATH-2150 must seek written instructor approval prior to registration.

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Projects (4 total) | 40% |
| Midterm Examination | 20% |
| Final Examination | 25% |
| Weekly Lab Exercises | 10% |
| Class Participation & Quizzes | 5% |

**Programming Projects** are the core assessment vehicle for this course. The four projects progress in complexity: (1) a 2D transformation and clipping engine, (2) a software rasterizer, (3) a scene renderer implementing the Phong illumination model with texture support, and (4) an open-ended final graphics application developed using OpenGL or Vulkan. Projects are submitted individually unless the supervising instructor explicitly designates a project as a paired assignment.

**Examinations** are closed-book and will assess conceptual understanding, mathematical derivations, and analysis of algorithms covered in lecture. A formula sheet of approved notations will be provided for both the midterm and final examinations.

**Lab Exercises** are completed during scheduled lab sections and assess students' working familiarity with the graphics API, shader programming, and debugging practices introduced that week.
