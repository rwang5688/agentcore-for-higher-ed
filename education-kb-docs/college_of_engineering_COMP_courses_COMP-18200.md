---

This course provides an in-depth exploration of XML (Extensible Markup Language) technologies and their integration with the Java programming language, equipping students with the skills to design, parse, and manipulate XML documents in enterprise and web-based applications. Students will examine core XML standards including DTD, XML Schema, XPath, and XSLT, applying these concepts through Java-based parsing frameworks such as DOM, SAX, and JAXB. Emphasis is placed on real-world application development scenarios, including data serialization, configuration management, and web service communication using XML-driven architectures.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design well-formed and valid XML documents using Document Type Definitions (DTDs) and XML Schema Definition (XSD) files, applying appropriate structural and data-type constraints.
- Implement Java-based XML parsing solutions using both event-driven (SAX) and tree-based (DOM) approaches, selecting the appropriate model based on performance and use-case requirements.
- Apply JAXB (Java Architecture for XML Binding) to marshal and unmarshal Java objects to and from XML representations in practical application development contexts.
- Construct XPath queries and XSLT stylesheets to navigate, transform, and present XML data across varying output formats including HTML and plain text.
- Evaluate and apply XML-based web service standards, including RESTful and SOAP service interactions, within Java application frameworks.

### Prerequisites

Students must have successfully completed the following before enrolling in COMP-18200:

- **COMP-11100 Introduction to Programming with Java** or equivalent with a grade of C or higher
- **COMP-14300 Data Structures and Algorithms**
- **COMP-15500 Web Technologies Fundamentals** (recommended, not required)

Students are expected to have working familiarity with object-oriented programming principles, basic file I/O operations in Java, and a foundational understanding of markup languages such as HTML. Students without prior exposure to Java are strongly encouraged to consult their academic advisor before enrolling.

### Assessment Methods

Student performance in this course will be evaluated through the following components:

| Assessment | Weight |
|---|---|
| Programming Assignments (4 total) | 35% |
| Midterm Examination | 20% |
| Group Project | 25% |
| Final Examination | 15% |
| Participation & Lab Activities | 5% |

**Programming Assignments:** Four individual assignments distributed throughout the semester, each targeting a specific technical competency — XML document design and validation, DOM/SAX parsing, JAXB binding, and XPath/XSLT transformation. Assignments are submitted via the course repository system and assessed on correctness, code quality, and documentation.

**Midterm Examination:** A closed-book written examination covering foundational XML concepts, schema design, and introductory Java parsing techniques. A short practical component requiring students to trace or complete code snippets may be included.

**Group Project:** Completed in teams of three to four students, the group project requires the design and implementation of a Java application that consumes, transforms, and presents XML-based data from a simulated or live data source. A written technical report and a 15-minute presentation are required.

**Final Examination:** A comprehensive examination encompassing all course material, with emphasis on applied problem-solving involving XML technologies in Java environments. The final examination includes both theoretical questions and practical coding exercises.

**Participation & Lab Activities:** Weekly lab sessions include structured exercises reinforcing lecture content. Students are assessed on attendance, engagement, and completion of in-lab tasks.
