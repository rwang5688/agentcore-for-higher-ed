## Course Description

### Course Description

COMP-12800: Machine Learning Crash Course provides an accelerated yet rigorous introduction to the foundational principles, algorithms, and applications of machine learning within the context of modern computational systems. Students will explore supervised, unsupervised, and reinforcement learning paradigms, gaining practical experience implementing models and evaluating their performance on real-world datasets. This course is designed to equip students with both the theoretical grounding and hands-on skills necessary to apply machine learning techniques across a broad range of engineering and scientific domains.

---

### Learning Objectives

By the end of this course, students will be able to:

- Explain and compare core machine learning paradigms, including supervised, unsupervised, and reinforcement learning, and identify appropriate use cases for each
- Implement and evaluate fundamental machine learning algorithms — including linear regression, decision trees, k-nearest neighbours, and k-means clustering — using industry-standard programming tools and libraries
- Apply data preprocessing techniques such as feature selection, normalisation, and dimensionality reduction to prepare datasets for model training and evaluation
- Assess model performance using appropriate metrics and validation strategies, including cross-validation, confusion matrices, precision-recall analysis, and ROC curves
- Critically analyse the ethical implications of machine learning systems, including issues of bias, fairness, transparency, and accountability in automated decision-making

### Prerequisites

Students enrolling in COMP-12800 must have successfully completed the following or demonstrate equivalent competency:

- **COMP-10100: Introduction to Programming** — Proficiency in at least one high-level programming language (Python strongly recommended)
- **MATH-10250: Calculus I** — Foundational understanding of differentiation and optimisation
- **MATH-11300: Linear Algebra and Matrix Methods** — Working knowledge of vectors, matrices, and linear transformations
- **STAT-10800: Introduction to Probability and Statistics** — Familiarity with probability distributions, statistical inference, and descriptive statistics

Students who have not completed the listed prerequisites may seek instructor permission to enrol on a case-by-case basis.

### Assessment Methods

| Assessment Component | Weight | Description |
|---|---|---|
| Programming Assignments (×4) | 40% | Four individual coding assignments requiring implementation and evaluation of machine learning algorithms using Python |
| Midterm Examination | 20% | Closed-book written examination covering theoretical concepts from Weeks 1–7 |
| Group Project | 25% | Teams of 3–4 students will identify a real-world problem, curate or source an appropriate dataset, train and evaluate a machine learning model, and present findings in a written report and oral presentation |
| Final Examination | 15% | Comprehensive closed-book examination spanning all course material |

**Note:** All programming assignments must be submitted via the Peculiar U course portal by 11:59 PM on the stated due date. Late submissions will incur a penalty of 10% per calendar day unless a formal extension has been granted. Group project presentations will be scheduled during the final two weeks of the term.
