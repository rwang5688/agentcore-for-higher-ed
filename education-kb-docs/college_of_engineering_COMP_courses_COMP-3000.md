## Course Description

### Course Description

COMP-3000: Codecademy provides students with a structured, hands-on introduction to foundational programming concepts and software development practices through guided interactive exercises and project-based learning. Students will explore core programming paradigms, data structures, and algorithmic thinking using modern programming languages and development environments. This course is designed to bridge theoretical computer science principles with practical coding proficiency, preparing students for more advanced study in the discipline.

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate fluency in at least one high-level programming language by writing syntactically correct, logically sound, and well-documented code
- Apply fundamental data structures — including arrays, linked lists, stacks, and queues — to solve computational problems of moderate complexity
- Analyze and implement basic algorithms, evaluating their efficiency using introductory Big-O notation
- Design and complete small-scale software projects that adhere to established coding conventions and best practices
- Debug and test programs systematically, identifying logical and runtime errors and applying appropriate corrective strategies

### Prerequisites

Students must have successfully completed the following before enrolling in COMP-3000:

- **COMP-1100: Introduction to Computing and Digital Systems** — Foundational literacy in computing hardware, software concepts, and binary logic
- **COMP-1250: Principles of Programming I** — Basic control flow, variables, functions, and introductory object-oriented concepts
- **MATH-1400: Discrete Mathematics for Computer Science** — Recommended co-requisite or prior completion; supports logical reasoning and algorithmic thinking

Students who have not completed the above prerequisites must obtain written approval from the course instructor or department advisor prior to registration.

### Assessment Methods

Student performance in COMP-3000 will be evaluated through the following components:

- **Weekly Coding Exercises (20%)** — Short, structured programming tasks submitted through the course's online development environment, assessed for correctness, efficiency, and code style
- **Midterm Examination (20%)** — A written and practical examination covering data structures, algorithm design, and debugging methodology administered in week seven of the semester
- **Module Projects — Three Total (30%)** — Three progressive software development projects of increasing complexity, each requiring submission of functional code, a brief technical write-up, and a peer code review participation component
- **Final Capstone Project (20%)** — An independently designed and implemented software application demonstrating mastery of course objectives, accompanied by a formal presentation to the course instructional team
- **Participation and Professionalism (10%)** — Active engagement in lab sessions, discussion boards, and collaborative coding workshops, as assessed by the instructional team
