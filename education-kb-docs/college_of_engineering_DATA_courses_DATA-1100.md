This graduate-level course provides a comprehensive introduction to the professional tools and computational environments that underpin modern data science workflows. Students will develop proficiency in industry-standard productivity platforms, version control systems, collaborative coding environments, and data pipeline utilities essential for rigorous, reproducible research and applied practice. Emphasis is placed on integrating these tools into cohesive, efficient workflows that meet the demands of advanced data science projects at the graduate level.

### Learning Objectives

Upon successful completion of DATA-1100, students will be able to:

- Demonstrate fluency in command-line interfaces, shell scripting, and environment management tools such as Conda and virtual environments for reproducible computational work
- Implement version control practices using Git and collaborative platforms to manage codebases, track project history, and contribute effectively to team-based data science projects
- Construct and document end-to-end data workflows using notebook environments, task automation tools, and integrated development environments appropriate for large-scale data analysis
- Evaluate and apply project management and collaboration platforms to coordinate multi-stakeholder data science initiatives with transparency and efficiency
- Apply best practices in data documentation, code readability, and workflow standardisation to produce professional-grade, reproducible analyses

### Prerequisites

Students enrolling in DATA-1100 should have completed or hold equivalent preparation in the following areas:

- Foundational proficiency in at least one programming language (Python or R strongly recommended)
- Completion of an undergraduate-level course in statistics, data analysis, or a closely related quantitative discipline
- Admission to a graduate programme within the College of Engineering or departmental instructor approval

Students without formal programming coursework but with demonstrable applied experience may petition the Department of Data Science for a prerequisite waiver.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Weekly Tool Practicals | 20% | Short, graded lab exercises completed during or following each class session, assessing hands-on proficiency with tools introduced that week |
| Midterm Portfolio Review | 25% | A curated portfolio of completed workflows, scripts, and documented projects submitted at mid-semester, evaluated for technical accuracy and professional presentation |
| Collaborative Group Project | 30% | A team-based project requiring students to design, document, and deliver a fully reproducible data science pipeline using tools covered across the course |
| Final Individual Report | 20% | A written technical report reflecting on tool selection decisions made throughout the course, demonstrating critical evaluation of productivity tools in a research or applied context |
| Participation & Peer Review | 5% | Active engagement in class discussions, peer code reviews, and collaborative feedback sessions |
