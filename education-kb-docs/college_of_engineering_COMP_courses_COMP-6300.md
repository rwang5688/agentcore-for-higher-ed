## Course Description

### Course Description

This advanced course provides an in-depth exploration of iOS application development with a specialized focus on building data visualization and analytical insight tools for the iPad platform. Students will engage with Apple's native development frameworks—including SwiftUI, UIKit, and the Charts framework—to design and implement sophisticated visual interfaces capable of transforming complex datasets into meaningful, interactive displays. Emphasis is placed on both technical proficiency and principled design thinking, ensuring graduates are equipped to deliver production-quality visualization applications in professional and research contexts.

---

### Learning Objectives

By the end of this course, students will be able to:

- Design and develop fully functional iPad applications using Swift and Apple's native SDK, adhering to current App Store guidelines and Human Interface Design principles
- Implement a range of data visualization techniques—including interactive charts, graphs, heatmaps, and spatial overlays—using both native frameworks and third-party libraries
- Integrate external data sources, APIs, and persistent local storage solutions to power dynamic, real-time visualizations within an iOS environment
- Apply principles of cognitive load theory and visual perception to critically evaluate and refine the communicative effectiveness of data-driven interfaces
- Architect scalable, maintainable application codebases using established design patterns such as MVVM and Combine, with consideration for accessibility and multi-device responsiveness

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Programming Assignments (×4) | 30% | Incremental coding tasks targeting specific visualization techniques and framework capabilities |
| Midterm Examination | 15% | Written and practical assessment covering core iOS development concepts and design theory |
| Design Critique Portfolio | 10% | Documented critical evaluations of existing iPad visualization applications, assessed against course design principles |
| Group Development Sprint | 15% | Collaborative two-week sprint resulting in a functional visualization prototype, assessed via peer review and instructor evaluation |
| Capstone Application Project | 30% | Individual end-to-end iPad application developed around a self-selected dataset and domain, presented in a formal demonstration session |

Participation in weekly code review sessions and design critiques is mandatory and contributes to the instructor's holistic assessment of professional engagement throughout the semester.
