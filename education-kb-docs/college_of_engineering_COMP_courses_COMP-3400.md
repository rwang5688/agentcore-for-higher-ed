This course provides a rigorous examination of the structural and functional design of modern computer systems, exploring the relationship between hardware components and the software that directs them. Students will investigate processor design, memory hierarchy, instruction set architectures, and parallel processing paradigms from both theoretical and applied perspectives. Emphasis is placed on understanding how architectural decisions impact system performance, efficiency, and scalability in contemporary computing environments.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Analyse and interpret the organisation of major hardware components, including the CPU, memory subsystems, and input/output interfaces, and explain how these components interact within a complete computer system
- Design and evaluate instruction set architectures (ISAs), distinguishing between RISC and CISC design philosophies and assessing the trade-offs inherent in each approach
- Apply knowledge of pipelining, branch prediction, and hazard mitigation strategies to assess and improve processor throughput and performance
- Explain the structure and function of memory hierarchy systems — including cache design, virtual memory, and paging mechanisms — and evaluate their impact on overall system performance
- Demonstrate familiarity with parallel and multi-core architectures, including Flynn's taxonomy and shared-memory models, and apply this understanding to analyse real-world performance scenarios

### Prerequisites

Students must have successfully completed the following prior to enrolment:

- **COMP-2210: Digital Logic and Circuit Design** or equivalent
- **COMP-2250: Introduction to Systems Programming** or equivalent
- **COMP-2180: Data Structures and Algorithms**

A working knowledge of low-level programming (C or Assembly) is strongly recommended. Students who have not completed the above prerequisites must seek written approval from the course coordinator or their academic adviser before registering.

### Assessment Methods

| Assessment Component | Weight | Details |
|---|---|---|
| Midterm Examination | 25% | Closed-book written examination covering ISA design, processor organisation, and pipelining concepts |
| Final Examination | 30% | Comprehensive closed-book examination spanning all course material |
| Lab Assignments (×4) | 25% | Practical lab exercises involving simulation tools and low-level programming tasks; completed individually or in pairs |
| Architecture Design Project | 15% | A group project (2–3 students) requiring the design and documentation of a simplified processor architecture using a hardware description language (HDL) or simulation environment |
| Participation & Quizzes | 5% | In-class quizzes and active participation in discussion sessions |

*Note: A minimum passing grade of 50% on the combined examination components is required to pass the course, regardless of overall weighted average.*
