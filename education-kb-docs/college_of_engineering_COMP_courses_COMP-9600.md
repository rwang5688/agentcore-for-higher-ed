## Course Description

### Course Description

COMP-9600: Introduction to Computer Science: Programming Paradigms provides an advanced exploration of the foundational theoretical and practical frameworks that underpin modern software development, with particular emphasis on comparative analysis across imperative, declarative, functional, object-oriented, and logic-based paradigms. Students engage with the philosophical and computational underpinnings of each paradigm, examining how design choices at the language level influence program correctness, scalability, and maintainability. This course is designed for graduate-level students seeking a rigorous synthesis of programming language theory and applied paradigm fluency within complex, real-world engineering contexts.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Critically evaluate and compare the structural characteristics, strengths, and limitations of major programming paradigms, including functional, object-oriented, imperative, declarative, and logic-based approaches.
- Design and implement non-trivial software solutions by deliberately selecting and applying paradigms appropriate to the problem domain, justifying those selections with theoretical grounding.
- Analyze the semantic and syntactic properties of programming languages through formal models, including lambda calculus foundations, type systems, and evaluation strategies.
- Demonstrate proficiency in at least three paradigm-representative languages (such as Haskell, Prolog, and a multi-paradigm language of study), producing well-structured, documented, and tested code artifacts.
- Synthesize research literature and technical documentation to articulate the historical evolution of programming paradigms and project informed perspectives on emerging paradigm trends in contemporary software engineering.

### Assessment Methods

Student performance will be evaluated through the following components:

| Assessment Component | Weight |
|---|---|
| Programming Assignments (5 total) | 30% |
| Midterm Examination | 15% |
| Research Paper and Presentation | 20% |
| Paradigm Comparative Analysis Project | 25% |
| Seminar Participation and Peer Review | 10% |

**Programming Assignments:** Five structured assignments, each requiring implementation of defined problem sets using a specified paradigm and language. Assignments are designed to build progressively in complexity, culminating in a multi-paradigm integration challenge.

**Midterm Examination:** A written examination assessing theoretical knowledge of paradigm semantics, type theory, formal language models, and evaluative reasoning. Both closed-form and open-response questions are included.

**Research Paper and Presentation:** A 6,000–8,000-word scholarly paper examining a paradigm-related research problem of the student's choosing, situating the work within current literature. Students will present findings during a scheduled seminar session and respond to peer and faculty questions.

**Paradigm Comparative Analysis Project:** A team-based project (groups of two to three) requiring the design, implementation, and formal written comparison of a single non-trivial software system built in parallel using three distinct paradigms. Final deliverables include source code, test suites, technical documentation, and a reflective analytical report.

**Seminar Participation and Peer Review:** Active engagement in weekly seminar discussions, including structured peer review of two fellow students' research paper drafts and meaningful contribution to paradigm debates and case study analyses.
