## Course Description

### Course Description

This course provides a rigorous examination of the foundational principles underlying modern computer architecture, with particular emphasis on the design, organization, and performance optimization of digital computing systems as understood in the early 2010s technological landscape. Students will explore the interplay between hardware and software, investigating how architectural decisions at the component level propagate to system-wide behavior and computational efficiency. Advanced topics include processor pipeline design, memory hierarchy, instruction set architectures, and parallel processing paradigms, equipping students with both theoretical grounding and practical analytical skills.

### Learning Objectives

By the end of this course, students will be able to:

- Analyze and evaluate the structural organization of modern CPU architectures, including pipelining, superscalar execution, and branch prediction mechanisms
- Design and assess memory hierarchy systems, including cache design strategies, virtual memory management, and storage subsystem integration
- Interpret and construct programs using assembly-level and machine-level instruction set architectures (ISAs), demonstrating an understanding of the relationship between high-level code and hardware execution
- Apply performance measurement methodologies, including Amdahl's Law and benchmarking techniques, to critically evaluate architectural trade-offs in real-world system design scenarios
- Evaluate the principles underlying multicore and parallel processor architectures, including inter-processor communication, synchronization, and coherence protocols

### Prerequisites

Given the advanced level of this course (Level 8635), students are expected to have successfully completed the following prior to enrollment:

- **COMP-6100: Digital Logic and Circuit Design** or equivalent — foundational understanding of Boolean algebra, combinational and sequential logic, and digital circuit construction
- **COMP-6450: Systems Programming and Assembly Language** — proficiency in low-level programming, memory addressing, and register-based computation
- **COMP-7200: Operating Systems Principles** — working knowledge of process management, memory management, and hardware-software interfacing
- **COMP-7580: Data Structures and Algorithm Analysis** — ability to reason about computational complexity and algorithmic efficiency as relevant to architectural performance
- Instructor consent required for students who have not completed the above through Peculiar U but hold demonstrably equivalent preparation from another accredited institution

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Midterm Examination | 20% | Closed-book written examination covering processor design, ISA fundamentals, and pipelining concepts |
| Final Examination | 25% | Comprehensive closed-book examination spanning all course material, with emphasis on synthesis and applied analysis |
| Architecture Design Project | 30% | A semester-long group project (teams of 2–3) in which students design, simulate, and critically evaluate a simplified processor architecture using industry-standard simulation tools; a formal written report and oral presentation are required |
| Problem Sets (×5) | 15% | Five written problem sets distributed throughout the semester, addressing quantitative performance analysis, cache computation, and pipeline hazard identification |
| Research Paper | 10% | An individual 8–10 page research paper examining a significant development in computer architecture from the period 2000–2013, situating it within the broader historical and technical context of the field |
