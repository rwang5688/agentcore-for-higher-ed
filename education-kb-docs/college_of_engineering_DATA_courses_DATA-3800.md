---

This course introduces students to the principles, tools, and workflows necessary for conducting and communicating data-driven research in a transparent and reproducible manner. Students will develop practical skills in version control, dynamic reporting, and data pipeline management, enabling them to produce analyses that can be independently verified and reliably replicated by others. Emphasis is placed on cultivating professional habits aligned with open science standards and industry best practices in data science.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement end-to-end reproducible data analysis workflows using industry-standard tools including version control systems, containerisation platforms, and literate programming environments
- Apply best practices in data management, including documentation, provenance tracking, and directory organisation, to ensure the long-term interpretability and reusability of research outputs
- Construct dynamic, executable research reports that integrate code, results, and narrative in a single coherent document using tools such as R Markdown, Quarto, or Jupyter Notebooks
- Critically evaluate existing data analyses and published research for reproducibility, identifying common sources of irreproducibility such as undisclosed data processing steps, dependency mismanagement, and statistical reporting errors
- Collaborate effectively on data science projects using distributed version control workflows, including branching strategies, pull requests, and conflict resolution

### Prerequisites

Students must have completed the following prior to enrolling in DATA-3800:

- **DATA-2210: Introduction to Data Science** or equivalent, with a grade of C or better
- **DATA-2450: Statistical Computing and Programming** or equivalent
- **MATH-2310: Probability and Applied Statistics** or equivalent
- Demonstrated working knowledge of at least one programming language commonly used in data analysis (R or Python recommended); students uncertain about their eligibility should consult their academic advisor or the Department of Data Science directly

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Reproducibility Audit Project | 25% | Students select a published data analysis or research paper and conduct a structured reproducibility audit, documenting findings in a written technical report |
| Reproducible Analysis Portfolio | 30% | A semester-long portfolio of data analysis assignments, each submitted as a fully reproducible, version-controlled project with accompanying documentation |
| Midterm Examination | 15% | Written examination covering conceptual foundations of reproducibility, version control theory, and data management principles |
| Final Collaborative Project | 25% | Team-based project in which student groups design, execute, and present a reproducible research pipeline on a dataset of their choosing, with peer review component |
| Participation and Lab Exercises | 5% | In-class and laboratory activities assessing engagement with hands-on reproducibility tools and workflows |

*Note: All project submissions must be accompanied by a publicly accessible or instructor-accessible version control repository. Submissions that cannot be independently executed from the repository will receive a grade reduction at the instructor's discretion.*

### Required Materials

Students are expected to obtain the following materials prior to the first week of class:

- Calloway, R. H. (2020). *Version Control and Collaborative Science: Git, Workflows, and Open Scholarship*. Northgate Technical Publishers. ISBN 978-0-38291-445-9
- Supplementary readings, laboratory worksheets, and dataset packages will be distributed through the course management system at no additional cost

*Software requirements: Students will require access to R (≥ 4.2), RStudio or VS Code, Python (≥ 3.10), Git, and Docker Desktop. All required software is freely available and installation guides are provided in the course orientation module. Computing lab access is available for students who require it through the College of Engineering facilities.*
