## Course Description

### Course Description

COMP-16500: Software Engineering: Introduction provides students with a comprehensive foundation in the principles, methodologies, and practices that underpin the professional development of large-scale software systems. Students will examine the full software development lifecycle, including requirements analysis, system design, implementation strategies, testing, and maintenance, with an emphasis on industry-standard tools and collaborative workflows. This course bridges theoretical computer science knowledge with the practical engineering discipline required to build reliable, maintainable, and scalable software solutions.

---

### Learning Objectives

By the end of this course, students will be able to:

- Articulate and apply core software engineering principles, including modularity, abstraction, and separation of concerns, within the context of real-world system design
- Analyze and document software requirements through the use of use case diagrams, user stories, and formal specification techniques
- Design software architectures using established patterns and evaluate trade-offs between competing design decisions
- Apply and compare major software development methodologies, including Agile, Scrum, and Waterfall, selecting appropriately for a given project context
- Collaboratively plan, implement, test, and deliver a software project using version control systems and project management tools in a team environment

---

### Prerequisites

Students must have successfully completed the following courses prior to enrollment:

- **COMP-24100: Data Structures and Algorithms** — Foundational knowledge of algorithmic thinking and data organization is essential for design and implementation work undertaken in this course
- **COMP-21200: Object-Oriented Programming** — Proficiency in at least one object-oriented language (preferably Java or Python) is assumed throughout all coursework
- **COMP-23300: Discrete Mathematics for Computing** — Logical reasoning and formal methods introduced in this course are applied to requirements specification and system modeling

Students who have not completed the above prerequisites must obtain written approval from the Department of Computer Science prior to registration.

### Assessment Methods

| Assessment Component | Weight | Details |
|---|---|---|
| Team Software Project | 35% | Completed in groups of 4–5; students will design, develop, test, and present a functional software system over the course of the semester |
| Midterm Examination | 20% | Closed-book written examination covering software lifecycle models, requirements engineering, and design principles |
| Final Examination | 20% | Comprehensive closed-book examination with emphasis on testing methodologies, project management, and architectural patterns |
| Design Documentation Portfolio | 15% | Individual submission of UML diagrams, requirements specifications, and architectural documentation produced throughout the semester |
| Weekly Participation and Lab Exercises | 10% | Short in-class and lab-based exercises assessing ongoing engagement with course material; graded on completion and quality |

*Note: A minimum passing grade of 50% must be achieved in both the Team Software Project and the Final Examination independently in order to receive a passing grade for the course.*

### Required Materials and Textbooks

Students are expected to obtain the following materials before the first week of class. All texts are available through the Peculiar U campus bookstore and the university library's digital lending portal.
