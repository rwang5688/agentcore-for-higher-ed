## Course Description

**COMP-11600 | Introduction to Python: Fundamentals**
*Credit Points: 4 | Department of Computer Science | College of Engineering*

---

This course provides an advanced-level examination of the Python programming language, with emphasis on foundational syntax, data structures, and programmatic problem-solving as applied within complex computational and engineering contexts. Students will develop rigorous proficiency in Python's core features while situating their technical skills within broader software development methodologies and best practices. The course is designed to ensure that students with prior programming experience can consolidate and formalize their understanding of Python as a professional-grade tool for research, engineering applications, and systems design.

---

### Learning Objectives

Upon successful completion of COMP-11600, students will be able to:

- Demonstrate fluency in Python syntax, control flow structures, and built-in data types, applying these elements to solve complex, domain-specific computational problems
- Design and implement modular, reusable Python programs utilizing functions, classes, and object-oriented programming principles consistent with professional software engineering standards
- Apply Python's standard library and selected third-party packages to tasks involving data manipulation, file I/O, and algorithmic processing
- Critically evaluate and debug existing Python codebases, identifying inefficiencies, logic errors, and opportunities for optimization
- Integrate Python programming competencies into collaborative, multi-disciplinary engineering workflows, including version control practices and documentation conventions

---

### Prerequisites

Students enrolling in COMP-11600 must have completed the following or demonstrated equivalent competency through departmental assessment:

- **COMP-31200** — Principles of Software Engineering *(minimum grade: C+)*
- **COMP-28450** — Data Structures and Algorithmic Analysis *(minimum grade: C+)*
- **COMP-30100** — Object-Oriented Programming Concepts *(minimum grade: C)*
- **MATH-21300** — Discrete Mathematics for Computing *(minimum grade: C)*

Students who have not completed the above prerequisites must obtain written permission from the course coordinator or their academic advisor prior to registration. Prior exposure to at least one high-level programming language is strongly recommended.

### Assessment Methods

Student performance in COMP-11600 will be evaluated through the following components:

| Assessment Component | Weight | Description |
|---|---|---|
| Programming Assignments (×6) | 30% | Weekly or bi-weekly coding tasks targeting specific module content |
| Midterm Examination | 20% | Written and practical examination covering Modules 1–5 |
| Final Examination | 25% | Comprehensive written and practical examination |
| Collaborative Project | 20% | Small-group software development project with written report |
| Participation & Lab Notebooks | 5% | Engagement in lab sessions and maintenance of a documented coding journal |

**Programming Assignments** are submitted via the university's designated code repository platform and are assessed on correctness, efficiency, readability, and adherence to documentation standards.

**The Collaborative Project**, completed in groups of three to four students, requires the design, implementation, testing, and presentation of a Python application addressing a real-world engineering or computational problem. A written technical report of approximately 2,500–3,500 words is required as part of the final submission.

**Examinations** include a combination of multiple-choice questions, short written responses, and practical coding segments completed in a supervised laboratory environment. Students may not use external resources during examination sessions unless explicitly permitted.
