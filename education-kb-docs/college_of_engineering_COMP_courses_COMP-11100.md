## Course Description

### Course Description

This graduate-level course provides a comprehensive introduction to the design and development of native applications for Apple's iOS platform using the Swift programming language and Xcode development environment. Students will explore the foundational principles of mobile user interface design, application architecture, and platform-specific development frameworks, with particular emphasis on Apple's UIKit and SwiftUI toolkits. By the end of the course, students will be equipped to conceive, design, build, and deploy functional iPhone applications that adhere to Apple's Human Interface Guidelines and industry best practices.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement functional iPhone applications using Swift and the Xcode integrated development environment, demonstrating proficiency in core iOS frameworks including UIKit and SwiftUI
- Apply established mobile user interface and user experience design principles in accordance with Apple's Human Interface Guidelines to produce intuitive, accessible, and aesthetically cohesive applications
- Architect iOS applications using recognized design patterns, including Model-View-Controller (MVC) and Model-View-ViewModel (MVVM), and manage application state and data persistence effectively
- Integrate native iOS device capabilities—such as GPS, camera, notifications, and network services—into functional application features using appropriate platform APIs
- Deploy applications to physical devices and the Apple App Store ecosystem, including performance profiling, debugging, and preparation of App Store submission materials

### Prerequisites

Students enrolling in COMP-11100 must have satisfied the following prerequisites prior to registration. Exceptions require written departmental approval.

- **COMP-58400 – Advanced Object-Oriented Programming** or demonstrated equivalent proficiency in an object-oriented programming language (e.g., Java, C++, Python)
- **COMP-61200 – Software Design and Architecture** or equivalent graduate-level coursework covering software design patterns and application lifecycle concepts
- Familiarity with version control systems, particularly Git, is strongly recommended
- Access to an Apple Mac computer running a current or recent version of macOS is a technical requirement for course participation, as Xcode is exclusive to the macOS platform; students without personal access should consult the department regarding laboratory resources

### Assessment Methods

Student performance will be evaluated through a combination of the following assessment instruments:

- **Laboratory Assignments (25%)** – A series of structured weekly coding exercises designed to reinforce lecture content and build progressive competency in Swift syntax, UIKit components, and iOS APIs. Assignments are submitted via the course's designated version control repository.
- **Midterm Examination (15%)** – A written and practical examination covering Swift language fundamentals, iOS application architecture, and core framework concepts introduced in the first half of the course.
- **Project Milestone Reviews (20%)** – Three formally assessed milestone checkpoints corresponding to the planning, prototype, and beta stages of the course's primary development project, evaluated by both the supervising instructor and peer reviewers.
- **Final Application Project (30%)** – A fully functional, individually developed iPhone application submitted with accompanying technical documentation, a design rationale report (minimum 2,500 words), and a live demonstration presented to the course faculty panel during the final examination period.
- **Participation and Peer Review (10%)** – Active engagement in seminar discussions, in-class code reviews, and structured peer evaluation sessions throughout the semester.
