## Course Description

### Course Description

This course provides a comprehensive introduction to the R programming language as applied to data science workflows, covering foundational syntax, data manipulation, and visualization techniques essential for modern data analysis. Students will gain hands-on experience working with real-world datasets using industry-standard R packages and tools, including the tidyverse ecosystem. By the end of the course, students will be equipped to independently perform exploratory data analysis and communicate findings through reproducible, well-documented code.

### Learning Objectives

Upon successful completion of DATA-2800, students will be able to:

- Write syntactically correct and well-structured R code to import, clean, and transform datasets of varying formats and complexity
- Apply core data manipulation techniques using packages such as `dplyr` and `tidyr` to filter, aggregate, and reshape data
- Produce informative and publication-quality visualizations using `ggplot2` and related graphical libraries
- Conduct basic exploratory data analysis, including descriptive statistics and identification of patterns, outliers, and missing data
- Develop reproducible analytical reports and workflows using R Markdown and version-controlled project environments

### Prerequisites

Students enrolling in DATA-2800 must have successfully completed the following, or obtained instructor permission:

- **DATA-1100: Foundations of Data Science** — Introduction to data concepts, the data science lifecycle, and basic computational thinking
- **MATH-1200: Introduction to Statistics** — Coverage of descriptive statistics, probability fundamentals, and introductory inferential methods
- **CS-1050: Introduction to Programming** — Familiarity with at least one programming language (Python, Java, or equivalent); no prior experience with R is required

Students without a formal programming background are strongly encouraged to consult with the course coordinator before registering.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Weekly Lab Assignments | 30% | Ten short, graded lab exercises completed during scheduled lab sessions, assessing incremental R programming skills |
| Midterm Examination | 20% | A written and practical exam covering R syntax, data manipulation, and foundational data analysis concepts |
| Data Analysis Projects (×2) | 30% | Two independent analysis projects in which students apply course techniques to instructor-provided or self-sourced datasets; submissions must include fully reproducible R Markdown reports |
| Final Examination | 15% | A comprehensive practical exam administered in the department computing lab, requiring students to complete a structured data analysis task under timed conditions |
| Participation & Peer Review | 5% | Active engagement in class discussions and structured peer review of a fellow student's project report |

Late submissions will be penalized at 10% per calendar day unless an extension has been approved in advance by the supervising instructor.
