## Course Description

### Course Description

Introduction to Computer Graphics provides students with a comprehensive foundation in the principles and techniques underlying the generation, manipulation, and rendering of visual content through computational methods. Topics include coordinate systems and geometric transformations, rasterization, shading models, texture mapping, and an introduction to real-time and offline rendering pipelines. Students will engage with both the theoretical underpinnings of graphical algorithms and their practical implementation using industry-relevant programming environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a thorough understanding of 2D and 3D coordinate systems, affine transformations, and projection models as applied in graphics pipelines.
- Implement core rendering algorithms, including rasterization, ray casting, and shading techniques, using a high-level graphics API.
- Analyse and apply illumination and reflectance models, including Phong, Blinn-Phong, and physically based shading frameworks, to produce photorealistic imagery.
- Evaluate and apply texture mapping, UV unwrapping, and procedural texturing methods within real-time rendering contexts.
- Design and develop original graphical applications that demonstrate mastery of the full rendering pipeline, from scene description to final image output.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Programming Assignments (×5) | 40% | Five incremental assignments covering transformation pipelines, shading, texture mapping, ray tracing, and a GPU rendering task |
| Midterm Examination | 15% | Written examination covering theoretical concepts from Weeks 1–7, including derivations and algorithm analysis |
| Final Examination | 20% | Comprehensive written examination spanning all course topics, with an emphasis on integration and synthesis of material |
| Research Paper | 10% | A 3,000–4,000 word critical review of a significant development or emerging trend in computer graphics research, submitted in IEEE format |
| Capstone Graphics Project | 15% | An individually or pair-developed graphical application demonstrating mastery of the rendering pipeline, accompanied by a technical report and in-class demonstration |

Students must achieve a passing grade in both the examination component and the programming component independently in order to pass the course overall. Late submissions are subject to a penalty of 10% per business day unless an extension has been granted in writing by the course coordinator.
