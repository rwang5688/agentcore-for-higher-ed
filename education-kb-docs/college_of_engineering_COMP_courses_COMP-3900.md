## Course Description

### Course Description

COMP-3900: Foundations of Computer & Information Security provides students with a comprehensive introduction to the principles, theories, and practices underlying modern cybersecurity. Students will examine the core concepts of protecting computing systems, networks, and data from unauthorized access, disruption, and exploitation, while exploring both offensive and defensive perspectives within the field. This course establishes the theoretical and practical groundwork necessary for advanced study in information security, cryptography, and network defense.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Identify and explain fundamental security concepts including confidentiality, integrity, availability, authentication, and non-repudiation within the context of modern computing environments
- Analyze common threat vectors, attack methodologies, and vulnerabilities affecting software, hardware, and networked systems
- Apply core cryptographic principles, including symmetric and asymmetric encryption, hashing, and digital signatures, to real-world security scenarios
- Evaluate and implement foundational access control models, security policies, and risk management frameworks in accordance with industry standards
- Demonstrate practical competency in identifying system vulnerabilities and proposing appropriate mitigation strategies through hands-on lab exercises

---

### Prerequisites

Students must have successfully completed the following courses prior to enrollment:

- **COMP-2210: Introduction to Computer Networks** — A foundational understanding of network protocols, topologies, and data communication is essential for engaging with network-level security concepts covered in this course
- **COMP-2150: Operating Systems Fundamentals** — Students must possess working knowledge of operating system architecture, process management, and file systems, as these topics underpin much of the course material
- **COMP-2050: Data Structures and Algorithms** — Proficiency in algorithmic thinking and data organization is required for understanding cryptographic algorithms and computational security models

Students who have not completed the above prerequisites must obtain written departmental approval prior to enrollment. A minimum cumulative GPA of 2.5 is recommended.

### Assessment Methods

| Assessment Component | Weight | Description |
|---|---|---|
| Midterm Examination | 20% | A written closed-book exam covering Modules 1–5, assessing students' understanding of foundational security concepts, threat modeling, and basic cryptography |
| Final Examination | 25% | A comprehensive closed-book exam spanning all course material, with emphasis on integrating concepts across security domains |
| Laboratory Assignments (×6) | 25% | Six guided hands-on lab sessions conducted in the Peculiar U Cybersecurity Lab, covering topics such as vulnerability scanning, password cracking fundamentals, firewall configuration, and basic penetration testing in sandboxed environments |
| Security Audit Project | 20% | A semester-long group project in which teams of three to four students conduct a simulated security audit of a provided fictional organizational case study, culminating in a written audit report and a 15-minute presentation |
| Weekly Problem Sets | 10% | Short written assignments submitted at the end of each instructional week to reinforce lecture material and reading comprehension |

**Note:** All laboratory work must be conducted exclusively within Peculiar U's authorized virtual lab environment. Any attempt to apply course techniques outside of designated environments constitutes a violation of the University's Academic Integrity Policy and may result in disciplinary action.
