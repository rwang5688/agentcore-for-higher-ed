### Course Description

This advanced course provides an in-depth examination of the theoretical foundations and practical design principles underlying programming languages, alongside a rigorous study of compiler construction and implementation. Students will explore the full compilation pipeline — from lexical analysis and parsing through semantic analysis, intermediate code generation, optimization, and target code generation — while critically comparing paradigms across procedural, object-oriented, functional, and logic-based languages. Emphasis is placed on building functional compiler components and understanding the formal systems that govern language specification and translation.

---

### Learning Objectives

By the end of this course, students will be able to:

- **Analyse and compare** the design principles, syntax, semantics, and type systems of major programming language paradigms, articulating trade-offs in expressiveness, safety, and performance.
- **Construct and implement** each major phase of a compiler, including a lexical analyser, recursive-descent parser, symbol table, semantic analyser, and basic code generator, using industry-standard tools and techniques.
- **Apply formal grammars** — including context-free grammars, BNF and EBNF notation, and automata theory — to define, parse, and validate the structure of programming languages.
- **Evaluate and apply** intermediate representation strategies and code optimisation techniques, including constant folding, dead code elimination, and register allocation, to improve program efficiency.
- **Design and present** a small but complete compiler or language interpreter project, demonstrating integration of theoretical knowledge with practical software engineering skills.

### Prerequisites

Students enrolling in COMP-15000 must have successfully completed the following or demonstrate equivalent competency:

- **COMP-11200 Data Structures and Algorithm Analysis** — Students must be comfortable with tree structures, recursion, and algorithm complexity, all of which are central to compiler construction.
- **COMP-11500 Discrete Mathematics for Computer Science** — A firm grounding in formal logic, set theory, and proof techniques is required, particularly for the study of formal grammars and automata.
- **COMP-12400 Systems Programming** — Experience with low-level memory management, pointers, and an understanding of machine-level code generation is essential.
- **COMP-13100 Theory of Computation** — Prior exposure to finite automata, regular expressions, and context-free languages is strongly recommended and assumed throughout the course.

Students who have not completed the above prerequisites must seek written permission from the course coordinator prior to enrolment.

### Assessment Methods

| Assessment Component | Weight | Details |
|---|---|---|
| Compiler Project (4 Phases) | 40% | A semester-long, incrementally submitted project in which students build a fully functional compiler for a simplified imperative language. Phases cover: (1) lexer, (2) parser and AST, (3) semantic analysis and type checking, and (4) code generation and basic optimisation. |
| Midterm Examination | 20% | A closed-book written examination covering formal grammars, parsing strategies (LL, LR), type systems, and early compilation phases. |
| Final Examination | 25% | A comprehensive closed-book examination spanning all course content, with emphasis on code optimisation, runtime environments, and language paradigm comparison. |
| Problem Sets (×4) | 10% | Four individual written and programming problem sets, distributed throughout the semester, addressing specific theoretical and applied topics covered in lectures. |
| Participation & In-Class Exercises | 5% | Active engagement in lecture discussions, in-class grammar and parsing exercises, and lab sessions. |

> *Note: Students must achieve a passing grade in both the compiler project and the final examination independently to receive a passing grade in the course overall. Late submissions
