## Course Description

### Course Description

COMP-16300: Signal Processing on Databases is an advanced graduate-level course that examines the intersection of classical signal processing theory and modern database systems, exploring techniques for acquiring, transforming, and analyzing signal-derived data within structured and unstructured database environments. Students will investigate methods for applying frequency-domain analysis, filtering, and spectral decomposition to large-scale datasets, with emphasis on real-time and batch processing architectures. The course bridges foundational signal processing mathematics with applied database engineering, preparing students to design robust systems capable of handling high-throughput signal data pipelines.

### Learning Objectives

By the end of this course, students will be able to:

- Apply core signal processing techniques — including Fourier transforms, convolution, and digital filtering — within the context of database query design and data retrieval optimization
- Design and implement database schemas and indexing strategies specifically optimized for time-series and frequency-domain signal data
- Evaluate and compare streaming versus batch processing architectures for ingesting and transforming large volumes of signal data at scale
- Develop analytical pipelines that integrate signal processing algorithms with SQL and NoSQL database environments, demonstrating proficiency in performance tuning and accuracy trade-offs
- Critically assess the computational complexity and storage implications of signal-based operations applied to relational and non-relational database systems

### Prerequisites

Given the advanced level of this course (880), students are expected to have completed the following prior to enrollment:

- COMP-52100: Advanced Database Systems or equivalent graduate-level database coursework
- COMP-54400: Digital Signal Processing Theory or equivalent
- COMP-51200: Algorithms and Complexity at the graduate level
- Demonstrated proficiency in at least one systems programming language (C++, Python, or Java) and familiarity with database query languages (SQL and/or NoSQL equivalents)
- Graduate standing in Computer Science, Electrical Engineering, or a closely related field; undergraduate students require written instructor permission

| Component | Weight | Description |

| Final Examination | 20% | Comprehensive written and computational exam spanning all course material |
| Research Paper | 25% | An individually authored 6,000–8,000-word scholarly paper investigating a novel application or open problem at the intersection of signal processing and database systems |
| Project (Group) | 25% | A semester-long group project requiring students to design, implement, and benchmark a signal processing pipeline integrated with a database backend of the group's choice; deliverables include a technical report and live demonstration |
