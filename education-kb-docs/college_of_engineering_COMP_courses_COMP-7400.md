## Course Description

### Course Description

COMP-7400: Graphics Architecture provides an advanced examination of the hardware and software systems underlying modern graphics pipelines, with emphasis on GPU microarchitecture, rendering subsystems, and the interaction between graphics APIs and physical hardware. Students will investigate the design principles of real-time and offline rendering architectures, exploring topics such as shader core organization, memory hierarchies, rasterization engines, and ray tracing acceleration structures. This course bridges theoretical computer architecture concepts with practical graphics programming, equipping students with the knowledge to design, evaluate, and optimize graphics systems at both the hardware and software level.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Analyze and compare the microarchitectural design of modern GPU hardware, including shader execution models, warp schedulers, and memory subsystem organization
- Evaluate the stages of programmable and fixed-function graphics pipelines and articulate how hardware design decisions influence rendering performance and throughput
- Design and implement graphics applications that exploit low-level hardware features through contemporary APIs such as Vulkan, DirectX 12, or Metal
- Apply optimization strategies for GPU workloads, including techniques related to memory bandwidth management, occupancy tuning, and parallelism exploitation
- Critically assess emerging graphics architectures, including ray tracing hardware units, neural rendering accelerators, and heterogeneous compute platforms

### Assessment Methods

| Component | Weight |
|---|---|
| Midterm Examination | 20% |
| Final Examination | 25% |
| Architecture Analysis Paper | 20% |
| Implementation Projects (×2) | 25% |
| Seminar Participation & Critique | 10% |

**Midterm and Final Examinations** assess students' theoretical understanding of GPU microarchitecture, pipeline design, and memory systems through a combination of short-answer and extended-response questions.

**Architecture Analysis Paper** (approximately 4,000–5,000 words) requires students to conduct an in-depth comparative analysis of two GPU architectures of their choosing, drawing on published hardware specifications, academic literature, and performance benchmarking data. A formal proposal is due in Week 4.

**Implementation Projects** are two substantial programming assignments. The first project requires students to implement a custom rendering pipeline using a low-level graphics API, demonstrating mastery of pipeline configuration and resource management. The second project tasks students with profiling and optimizing a provided GPU-bound workload, with a written report documenting findings and applied strategies.

**Seminar Participation & Critique** reflects engagement during in-class architectural case studies and student-led paper discussions drawn from current conference proceedings (SIGGRAPH, ISCA, Hot Chips).
