## Course Description

### Course Description

COMP-11300 provides an intensive introduction to computational thinking, algorithmic design, and foundational programming concepts for students at the advanced graduate level. Students will explore structured problem decomposition, logic formulation, and the implementation of solutions using a high-level programming language, with emphasis on writing clean, efficient, and well-documented code. This course serves as a gateway to advanced study in computer science, bridging theoretical principles of computation with applied programming practice.

### Learning Objectives

By the end of this course, students will be able to:

- Analyze complex problems and decompose them into logical, algorithmically solvable components using systematic problem-solving frameworks
- Design, write, test, and debug functional programs in a high-level programming language, demonstrating proficiency in core constructs including variables, control flow, loops, and functions
- Apply foundational data structures such as arrays, lists, and dictionaries to organize and manipulate data effectively within program solutions
- Evaluate the correctness and efficiency of algorithmic solutions, identifying opportunities for optimization and recognizing computational complexity trade-offs
- Communicate computational thinking through clear code documentation, technical commentary, and written reflection on design decisions

### Prerequisites

Given the graduate-level designation of this course (890), students are expected to meet the following prerequisites prior to enrollment:

- Completion of a bachelor's degree in Computer Science, Mathematics, Engineering, or a closely related discipline, or demonstrated equivalent professional experience
- Familiarity with discrete mathematics, including basic set theory, logic, and proof structures (equivalent to an undergraduate Discrete Mathematics course)
- Undergraduate-level exposure to at least one programming language or scripting environment is strongly recommended, though not strictly required
- Departmental approval may be required for students entering from non-technical undergraduate backgrounds; prospective students should consult with the College of Engineering graduate advising office

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Programming Assignments (6) | 40% | Weekly or bi-weekly coding assignments requiring students to implement algorithmic solutions to progressively complex problems |
| Midterm Examination | 15% | Written and practical exam covering problem decomposition, pseudocode design, and foundational programming constructs |
| Final Examination | 20% | Comprehensive examination assessing cumulative mastery of course content, including algorithm analysis and program design |
| Capstone Programming Project | 20% | An individually completed project in which students design, implement, document, and present a complete software solution addressing a self-identified computational problem |
| Participation & Code Reviews | 5% | Active engagement in structured peer code review sessions and in-class problem-solving discussions |

All programming assignments must be submitted via the university's designated course management portal by the posted deadline. Late submissions will be penalized at a rate of 10% per calendar day unless a documented extension has been granted by the supervising instructor.
