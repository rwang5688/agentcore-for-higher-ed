This course provides a rigorous, graduate-level examination of the computational tools and software ecosystems that underpin modern data science practice, with an emphasis on scalable workflows, reproducibility, and professional-grade implementation. Students will develop advanced proficiency in industry-standard programming environments, version control systems, data pipeline architectures, and visualisation frameworks as applied to complex, real-world datasets. The course bridges theoretical foundations with applied technical competency, preparing students to operate effectively within collaborative, data-driven research and engineering environments.

### Learning Objectives

Upon successful completion of DATA-1200, students will be able to:

- Demonstrate advanced command of Python and R for data manipulation, statistical analysis, and machine learning pipeline construction, selecting appropriate tools and libraries for a given analytical context
- Design and implement reproducible data science workflows using version control systems (including Git and associated platforms), containerisation tools, and documented coding standards appropriate for professional and research settings
- Construct, optimise, and critically evaluate data pipelines capable of handling large-scale structured and unstructured datasets, including integration with cloud-based storage and computing resources
- Develop compelling, publication-quality data visualisations and interactive dashboards that accurately and ethically communicate analytical findings to both technical and non-technical audiences
- Critically assess the suitability, limitations, and ethical implications of specific data science tools and methodologies within diverse applied domains, including considerations of bias, transparency, and data governance

### Prerequisites

Students enrolling in DATA-1200 must have completed the following, or demonstrate equivalent competency approved by the Department of Data Science:

- **DATA-0600: Foundations of Data Science** or equivalent introductory data science coursework
- **COMP-0550: Programming for Engineers** or demonstrated intermediate-level proficiency in Python or R
- **MATH-0600: Applied Statistics and Probability** or equivalent graduate-preparatory statistics course
- Familiarity with command-line interfaces and basic database querying (SQL) is strongly recommended; students without this background are encouraged to complete the department's non-credit preparatory module, *Technical Readiness in Data Environments*, prior to enrolment

### Assessment Methods

Student performance in DATA-1200 will be evaluated through the following components:

| Assessment | Weight | Description |
|---|---|---|
| Lab Assignments (×6) | 30% | Biweekly hands-on lab exercises requiring students to apply tools and techniques introduced in lecture to structured analytical tasks |
| Midterm Technical Examination | 15% | A closed-environment practical examination assessing proficiency in core programming, data manipulation, and pipeline construction skills |
| Reproducibility and Workflow Project | 25% | An individual project in which students document, containerise, and present a fully reproducible data science workflow applied to a dataset of their choosing, accompanied by a written technical report (2,000–3,000 words) |
| Group Capstone Project | 20% | A collaborative team project requiring end-to-end design and implementation of a data science solution, including a live demonstration and peer-reviewed written report |
| Participation and Professional Practice | 10% | Assessed contributions to seminar discussions, code review sessions, and adherence to collaborative coding and documentation standards throughout the term |

*Note: All submitted code and projects must conform to the departmental style guidelines outlined in the DATA-1200 Course Companion. Late submissions will be penalised in accordance with Peculiar U's standard academic policy unless an extension has been formally approved.*
