### Course Description

This course provides a rigorous yet accessible introduction to the theory and practice of machine learning using the Python programming language, with emphasis on developing working fluency in the tools, libraries, and workflows that underpin modern intelligent systems. Students will explore foundational algorithms including linear regression, decision trees, clustering, and neural networks, situating each within a broader conceptual framework of supervised, unsupervised, and reinforcement learning paradigms. By the conclusion of the course, students will be equipped to design, implement, evaluate, and critically interpret machine learning pipelines applied to real-world datasets.

---

### Learning Objectives

Upon successful completion of COMP-12900, students will be able to:

- **Demonstrate conceptual understanding** of core machine learning paradigms — supervised, unsupervised, and reinforcement learning — and articulate the appropriate contexts for applying each.
- **Implement and evaluate** foundational machine learning algorithms in Python using industry-standard libraries, including NumPy, pandas, scikit-learn, and introductory TensorFlow or PyTorch workflows.
- **Apply data preprocessing and feature engineering techniques**, including normalization, dimensionality reduction, and handling of missing or imbalanced data, to prepare datasets for model training.
- **Assess model performance** using appropriate metrics (e.g., accuracy, F1 score, mean squared error, ROC-AUC) and apply techniques such as cross-validation and hyperparameter tuning to improve predictive outcomes.
- **Communicate findings effectively** by producing written and visual summaries of experimental results, demonstrating awareness of ethical considerations including algorithmic bias, data privacy, and model transparency.

### Prerequisites

Students enrolling in COMP-12900 are expected to have completed the following, or to have obtained instructor consent:

- **COMP-10100: Introduction to Programming with Python** or equivalent demonstrated proficiency in Python programming, including control flow, functions, and basic object-oriented principles.
- **COMP-10400: Data Structures and Algorithms I** — familiarity with fundamental data structures (arrays, lists, dictionaries) and basic algorithmic complexity is assumed throughout the course.
- **MATH-11200: Linear Algebra for Computing** — working knowledge of vectors, matrices, matrix multiplication, and eigenvalues is required for understanding model mechanics.
- **MATH-10800: Introduction to Probability and Statistics** — students should be comfortable with probability distributions, hypothesis testing, descriptive statistics, and basic inferential reasoning.

Students who have not completed all listed prerequisites but possess equivalent background knowledge are encouraged to speak with one of the listed instructors during the first week of term regarding a prerequisite waiver.

### Assessment Methods

Student performance in COMP-12900 will be evaluated through a combination of the following components:

| Assessment Component | Weight | Details |
|---|---|---|
| Programming Assignments (×4) | 40% | Four individual coding assignments, each requiring students to implement and analyse a specific class of algorithms on provided datasets. Submitted via the course portal with accompanying written reflections. |
| Midterm Examination | 15% | A closed-book written examination covering theoretical foundations, algorithm mechanics, and conceptual reasoning from Weeks 1–7. |
| Group Project | 25% | Teams of 3–4 students will select a real-world problem domain, source or curate an appropriate dataset, and develop, evaluate, and present a complete machine learning pipeline. Final deliverables include a technical report (1,500–2,500 words) and an in-class presentation. |
| Final Examination | 15% | A comprehensive closed-book examination assessing the full scope of the course, with emphasis on integration of concepts across multiple modules. |
| Participation and Lab Engagement | 5% | Active contribution to weekly lab sessions and in-class discussions, assessed by instructors on a satisfactory/unsatisfactory basis across the term. |

*Note: All programming assignments must be submitted with clearly commented code and a brief explanatory write-up.
