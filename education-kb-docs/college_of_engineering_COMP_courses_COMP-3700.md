### Course Description

Computer Language Engineering provides a rigorous examination of the theory, design, and implementation of programming languages, with emphasis on the construction of compilers and interpreters for modern language paradigms. Students investigate the formal foundations of lexical analysis, parsing, semantic analysis, and code generation while developing practical experience building language toolchains from specification through execution. The course bridges classical automata and formal language theory with contemporary software engineering practices, equipping students with the skills to design, evaluate, and implement domain-specific and general-purpose programming languages.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement the core stages of a compiler pipeline, including lexical analysis, parsing, semantic analysis, optimization, and target code generation, demonstrating an integrated understanding of how each phase interacts within the broader translation process.
- Apply formal grammar formalisms — including context-free grammars, regular expressions, and BNF/EBNF notation — to specify the syntax of both existing and novel programming languages with precision and rigor.
- Construct and employ essential compiler data structures such as abstract syntax trees, symbol tables, and intermediate representations to support accurate and efficient language translation.
- Analyze and compare language design decisions across multiple programming paradigms — including imperative, functional, object-oriented, and logic-based languages — evaluating their practical and theoretical tradeoffs.
- Develop a working interpreter or compiler for a defined language subset, integrating appropriate testing, documentation, and software engineering practices consistent with professional standards.

### Prerequisites

Students must have satisfied the following requirements prior to enrolling in COMP-3700:

- **COMP-2200: Data Structures and Algorithm Analysis** — Students must demonstrate proficiency in fundamental data structures (trees, graphs, hash tables) and algorithmic analysis, as these are employed extensively throughout the compiler construction process.
- **COMP-2310: Formal Languages and Automata Theory** — A working knowledge of finite automata, pushdown automata, regular languages, and context-free languages is essential for understanding lexical analysis and parsing theory.
- **COMP-2150: Programming Paradigms** — Exposure to multiple programming language paradigms is required, as comparative language analysis forms a core component of the curriculum.

Students who have not completed the above prerequisites or hold equivalent transfer credit must obtain written departmental approval before registering for this course.

### Assessment Methods

Student performance in COMP-3700 will be evaluated through a combination of theoretical assessments and practical implementation work, distributed as follows:

- **Compiler Implementation Project (35%)** — A multi-stage semester-long project in which students design and implement a functioning compiler or interpreter for an assigned or approved language specification. The project is completed in phases with milestone submissions at weeks 5, 9, and 13, and concluded with a final submission and live demonstration during the examination period. Group collaboration of two to three students is permitted with documented individual contribution statements.

- **Programming Assignments (25%)** — A series of five shorter assignments targeting discrete compiler stages — including lexer construction, recursive descent parser implementation, symbol table design, type checking, and intermediate code generation — to reinforce lecture content through hands-on practice.

- **Midterm Examination (20%)** — A closed-book, in-class written examination covering formal grammar specification, scanning and parsing theory, parse tree and AST construction, and foundational semantic analysis concepts.

- **Final Examination (15%)** — A comprehensive written examination administered during the University's official final examination period, assessing the full breadth of course content with emphasis on code generation, optimization strategies, and language design principles.

- **Critical Language Analysis Paper (5%)** — A short analytical paper (1,500–2,500 words) in which students select an existing programming language and critically evaluate its design decisions, formal specification, and implementation approach in relation to concepts covered in the course.

*All submitted work must comply with Peculiar University's Academic Integrity Policy. Any use of automated code generation tools must be disclosed and is subject to instructor-specific guidelines published in the course syllabus.*
