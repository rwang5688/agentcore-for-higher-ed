## Course Description

### Course Description

COMP-7800 provides an advanced, structured introduction to programming in the Java language, designed for students with a strong computational background seeking to develop professional-level software development skills. Students will explore the foundational and intermediate principles of Java, including object-oriented design, memory management, and the Java Standard Library, with emphasis on writing clean, efficient, and maintainable code. The course bridges theoretical computer science knowledge with practical application, preparing students for enterprise-level Java development and advanced software engineering coursework.

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement object-oriented Java programs using core principles including encapsulation, inheritance, polymorphism, and abstraction
- Utilize Java's Standard Library and collection frameworks to develop robust, efficient applications
- Apply exception handling strategies and debugging methodologies to identify and resolve software defects in complex codebases
- Develop multi-threaded Java applications with an understanding of concurrency, synchronization, and thread lifecycle management
- Evaluate and refactor existing Java code for performance, readability, and adherence to industry-recognized design patterns and best practices

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- COMP-5400: Foundations of Algorithms and Data Structures (minimum grade: B)
- COMP-5550: Introduction to Object-Oriented Programming Concepts (minimum grade: B)
- COMP-6200: Software Design Principles or equivalent, as approved by the Department of Computer Science
- Demonstrated proficiency in at least one high-level programming language (e.g., Python, C++, or C#), verified through departmental assessment or prior coursework

Students who are uncertain about their eligibility are encouraged to consult with their academic advisor or contact the Department of Computer Science directly before registering.

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (6 total) | 35% |
| Midterm Examination | 20% |
| Group Software Development Project | 25% |
| Final Examination | 15% |
| Participation and Code Review Sessions | 5% |

**Programming Assignments:** Six individual assignments will be distributed throughout the semester, each targeting specific Java concepts covered in lecture. Assignments must be submitted via the university's code submission portal and will be evaluated on correctness, code quality, and documentation standards.

**Midterm Examination:** A written and practical examination covering topics from the first half of the course, including core syntax, object-oriented design, and the Java Standard Library. The practical component will require students to write and debug Java code under timed conditions.

**Group Software Development Project:** Teams of three to four students will design, implement, document, and present a substantial Java application of their choosing, subject to instructor approval. The project is intended to simulate a professional development environment and will be evaluated across multiple milestone submissions.

**Final Examination:** A comprehensive written and practical examination covering all course material, with emphasis on advanced topics including concurrency, design patterns, and performance optimization.

**Participation and Code Review Sessions:** Students are expected to actively engage in weekly code review discussions, offering constructive peer feedback and demonstrating an ability to critically analyze Java code written by others.
