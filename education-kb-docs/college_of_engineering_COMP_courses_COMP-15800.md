### Course Description

This course provides an in-depth exploration of Python programming principles, emphasizing the development of efficient, scalable, and maintainable code for real-world computational applications. Students will engage with core language features alongside widely adopted libraries and frameworks relevant to software development, data processing, and automation. Building upon prior programming experience, the course challenges students to apply advanced problem-solving strategies and software engineering best practices within the Python ecosystem.

---

### Learning Objectives

Upon successful completion of COMP-15800, students will be able to:

- **Design and implement** well-structured Python programs using object-oriented and functional programming paradigms, applying appropriate design patterns to solve complex software problems.
- **Utilize and critically evaluate** Python's standard library and third-party packages — including NumPy, Pandas, and Requests — to build efficient data-handling and application-layer solutions.
- **Apply debugging, testing, and profiling techniques** using tools such as PyTest and cProfile to produce reliable, optimized, and production-ready code.
- **Develop and deploy** modular Python applications that integrate file I/O, database connectivity, and RESTful API interactions within a version-controlled development environment.
- **Communicate technical decisions** clearly through documented codebases, written technical reports, and collaborative code review, demonstrating professional software development standards.

### Prerequisites

Students enrolling in COMP-15800 must have successfully completed the following, or obtained explicit written approval from the course instructor:

- **COMP-22100 — Foundations of Programming I** (minimum grade: C+)
- **COMP-24400 — Data Structures and Algorithms** (minimum grade: C+)
- **COMP-31200 — Object-Oriented Software Design** or equivalent, as determined by departmental assessment
- Demonstrated familiarity with at least one high-level programming language (e.g., Java, C++, or C#) as evidenced by prior coursework
- Working knowledge of command-line environments and version control systems (Git) is strongly recommended prior to enrolment

### Assessment Methods

Student performance in COMP-15800 will be evaluated through a combination of practical and theoretical assessment components as outlined below:

| Assessment Component | Weight | Details |
|---|---|---|
| Programming Assignments (×5) | 35% | Five progressive individual coding assignments submitted via the course repository platform, covering core topics introduced in each unit |
| Midterm Examination | 15% | Closed-book written examination assessing theoretical understanding of Python internals, syntax, and program logic |
| Group Software Project | 25% | A collaborative project completed in teams of 3–4 students, culminating in the delivery of a functional Python application with full documentation and a live demonstration |
| Technical Portfolio | 15% | An individually maintained and submitted portfolio of annotated code samples, reflective commentary, and design justifications developed across the semester |
| Final Examination | 10% | Practical, lab-based examination requiring students to write, debug, and optimise Python code under timed conditions |

*Note: A minimum combined score of 50% across examination components (Midterm and Final) is required to pass the course, regardless of overall weighted average.*
