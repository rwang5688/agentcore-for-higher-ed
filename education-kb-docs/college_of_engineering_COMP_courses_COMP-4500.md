## Course Description

### Course Description

COMP-4500 provides students with a foundational understanding of computational thinking, programming principles, and algorithmic problem-solving within a structured academic environment. Students will explore core concepts in software development, data representation, and the logical structures that underpin modern computing systems. This course serves as an entry point into the discipline of computer science, emphasizing both theoretical comprehension and practical application through hands-on programming exercises.

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate a working understanding of fundamental programming constructs, including variables, control flow, loops, and functions
- Apply algorithmic thinking to decompose complex problems into logical, solvable components
- Design and implement basic programs using an industry-relevant programming language
- Identify and describe core principles of data structures, including arrays, lists, and simple key-value mappings
- Evaluate and debug existing code to identify logical errors and improve program efficiency

### Prerequisites

- Successful completion of MATH-2100: Discrete Mathematics for Computing or equivalent
- COMP-3100: Foundations of Digital Systems or departmental consent
- A minimum cumulative GPA of 2.5 is recommended prior to enrollment

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (×6) | 30% |
| Midterm Examination | 20% |
| Laboratory Practicals (×4) | 20% |
| Final Project | 20% |
| Participation & In-Class Exercises | 10% |

**Programming Assignments** are submitted via the departmental coding portal and assessed on correctness, code quality, and documentation. **Laboratory Practicals** are conducted during scheduled lab sessions and test applied understanding of weekly material. The **Final Project** requires students to independently design and implement a small software application addressing a self-identified computational problem, accompanied by a written technical report of no fewer than 1,500 words.

### Required Materials

- Osei, M. & Lindqvist, A. (2016). *Data, Structure, and Design: Foundations of Computer Science*. Norbridge University Press.

Students are also required to have access to a personal computer capable of running the course-designated development environment (details provided during orientation week). All supplementary readings and lab materials will be made available through the Peculiar U course management portal at no additional cost.
