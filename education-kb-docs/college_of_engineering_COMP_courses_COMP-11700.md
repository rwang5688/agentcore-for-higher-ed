## Course Description

### Course Description

COMP-11700 provides a rigorous graduate-level exploration of TensorFlow as a foundational framework for developing artificial intelligence, machine learning, and deep learning systems. Students will progress from core TensorFlow architecture and tensor operations through the design, training, and evaluation of sophisticated neural network models, including convolutional, recurrent, and transformer-based architectures. Emphasis is placed on translating theoretical machine learning principles into scalable, production-ready implementations using contemporary TensorFlow and Keras APIs.

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate proficiency in TensorFlow's computational graph model, eager execution paradigm, and core tensor manipulation operations for building efficient machine learning pipelines
- Design, implement, and fine-tune deep neural network architectures — including CNNs, RNNs, LSTMs, and attention-based models — using the TensorFlow/Keras high-level API
- Apply best practices in model optimization, including regularization strategies, hyperparameter tuning, gradient descent variants, and learning rate scheduling, to improve model generalization and performance
- Construct and manage end-to-end machine learning workflows encompassing data ingestion, preprocessing via tf.data, model training, validation, checkpointing, and deployment using TensorFlow Serving
- Critically evaluate model performance using appropriate metrics and diagnostic tools, including TensorBoard, and communicate findings through rigorous technical documentation

### Prerequisites

Students enrolling in COMP-11700 must have completed the following or demonstrate equivalent competency:

- **COMP-10200: Foundations of Machine Learning** or equivalent graduate-level machine learning coursework
- **COMP-10050: Applied Linear Algebra and Probability for Data Science** or equivalent mathematical foundations course
- **COMP-09800: Programming with Python for Data Science** or demonstrated proficiency in Python programming, including familiarity with NumPy, Pandas, and Matplotlib
- Graduate standing within the College of Engineering or written permission from the course coordinator

Students without formal prerequisites may petition the department for enrollment by submitting a portfolio of relevant prior work for faculty review.

### Assessment Methods

Student performance will be evaluated through the following components:

- **Programming Assignments (30%):** A series of five structured coding assignments of increasing complexity, covering tensor operations, model construction, training pipelines, and transfer learning applications. Assignments are submitted via the course's version-controlled repository system and assessed on correctness, code quality, and documentation.
- **Midterm Examination (15%):** A written and computational examination assessing theoretical understanding of TensorFlow architecture, deep learning fundamentals, and model optimization principles. Students will answer conceptual questions and complete short implementation tasks in a supervised setting.
- **Deep Learning Implementation Project (35%):** A substantial semester-long individual or paired project requiring students to identify a real-world problem domain, design an appropriate deep learning solution in TensorFlow, and deliver a fully documented codebase, experimental results report, and a formal oral presentation to faculty and peers during the final two weeks of the semester.
- **Research Paper Analysis and Critique (10%):** Students will select an approved peer-reviewed publication from a venue such as NeurIPS, ICML, or ICLR, reproduce or adapt a key result using TensorFlow, and submit a written critique evaluating the methodology, reproducibility, and broader implications of the work.
- **Participation and Lab Engagement (10%):** Active, constructive participation in weekly laboratory sessions, in-class discussions, and peer code reviews, assessed by instructors on a rolling basis throughout the semester.
