### Course Description

This course introduces foundational programming concepts tailored specifically for students with a background in design disciplines, emphasising the creative and practical applications of code in visual, interactive, and user-centred contexts. Students will explore core programming logic, data structures, and algorithmic thinking through design-driven projects that bridge the gap between computational systems and aesthetic problem-solving. By the end of the course, students will be equipped to integrate programming tools confidently into their design practice and collaborate effectively within interdisciplinary technical environments.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Demonstrate a working understanding of fundamental programming concepts, including variables, control flow, functions, and loops, within a design-oriented framework
- Apply introductory coding skills using accessible programming environments to produce interactive and visually expressive outputs
- Analyse a design problem and develop a structured computational approach to its solution, translating creative intent into functional code
- Evaluate and select appropriate programming tools and libraries suited to specific design challenges and project requirements
- Communicate and document their coding processes clearly, presenting technically sound work that reflects both programmatic accuracy and design sensibility

### Prerequisites

Students enrolling in COMP-15100 are expected to have completed or be concurrently enrolled in the following:

- **COMP-10100: Introduction to Digital Technologies** or equivalent foundational computing literacy course
- **DSGN-10050: Foundations of Design Thinking** or any introductory design studio course
- No prior programming experience is required; however, students should demonstrate comfort with standard computer operations and file management

Students who are uncertain whether their prior coursework satisfies these prerequisites are encouraged to consult their academic advisor or reach out to one of the listed instructors before the semester begins.

### Assessment Methods

| Assessment Component | Weight | Description |
|---|---|---|
| Weekly Coding Exercises | 20% | Short in-class and take-home coding tasks assigned each week to reinforce lecture content |
| Midterm Project | 25% | A design-focused programming project requiring students to produce an interactive or generative visual artefact with accompanying documentation |
| Written Reflection Papers (×2) | 15% | Two short papers (600–800 words each) critically reflecting on the relationship between code and design practice |
| Final Project | 30% | A culminating independent project in which students identify a design problem and develop a coded solution, presented in a live showcase to peers and instructors |
| Participation & Peer Review | 10% | Active engagement in critiques, class discussions, and structured peer feedback sessions |

*Late submissions will be penalised at 5% per calendar day unless an extension has been formally agreed upon with the relevant instructor in advance.*

### Required Materials & Textbooks

Students are required to obtain the following materials prior to the first week of class. All titles are available through the Peculiar U campus bookstore and the university library's digital lending platform.

- **Bransky, L. & Chavelas, M.** (2021). *Code as Canvas: An Introduction to Programming for Creative Practitioners* (3rd ed.). Heliograph Academic Press. — Primary course text covering all core programming concepts addressed in lectures.

- **Marschel, A.** (2019). *Designing with Logic: Computational Thinking for Visual Artists and Designers*. Crossthread Publishing. — Supplementary reading focusing on design methodology and algorithmic approaches.

- **Petras, U. & Stasik, Z.** (2023). *Interactive by Design: Practical Exercises in Generative and Responsive Media*. Ironbridge Technical Press. — Lab workbook used in conjunction with weekly exercises and project briefs.

Students will also require access to **SketchScript Pro** (free educational licence available through the College of Engineering software portal) and a **Peculiar U student computing account** for submission and version control via the university's coding repository system.
