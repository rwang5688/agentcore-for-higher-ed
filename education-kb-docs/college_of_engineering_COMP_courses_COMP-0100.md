## Course Description

### Course Description

Advanced Algorithms provides students with a foundational introduction to the design, analysis, and implementation of computational algorithms, with emphasis on problem-solving strategies and algorithmic thinking. Students will explore core algorithm paradigms including sorting, searching, recursion, and basic data structures, developing the skills necessary to evaluate algorithmic efficiency and correctness. This course serves as an essential entry point into the theoretical and practical dimensions of computer science, preparing students for more complex computational study.

### Learning Objectives

By the end of this course, students will be able to:

- Understand and apply fundamental algorithm design techniques, including divide-and-conquer, greedy approaches, and recursive problem-solving
- Analyze the time and space complexity of basic algorithms using Big-O notation and asymptotic analysis
- Implement and evaluate common sorting and searching algorithms, including bubble sort, merge sort, binary search, and their variants
- Demonstrate proficiency in selecting appropriate algorithmic strategies for a given computational problem
- Communicate algorithmic solutions clearly through pseudocode, written documentation, and structured code implementation

### Prerequisites

There are no formal prerequisites for COMP-0100. However, students are strongly encouraged to have basic familiarity with mathematical reasoning and comfort with introductory computing concepts. Students who have completed a high school-level computer science or programming course will be well positioned for success.

### Assessment Methods

| Assessment | Weight |
|---|---|
| Weekly Problem Sets | 25% |
| Midterm Examination | 20% |
| Algorithm Implementation Projects (×2) | 30% |
| Final Examination | 20% |
| Participation and In-Class Exercises | 5% |

**Problem Sets:** Weekly written and coding assignments reinforce lecture content and build incremental algorithmic competency.

**Implementation Projects:** Two structured programming projects require students to design, implement, and document original algorithmic solutions to specified computational problems. Projects are submitted with accompanying written analyses of efficiency and design decisions.

**Examinations:** Both the midterm and final examinations include a combination of multiple-choice questions, short-answer algorithm analysis problems, and pseudocode writing tasks.
