## Course Description

### Course Description

COMP-15400 provides an advanced exploration of Python programming as applied to data science workflows and artificial intelligence systems, with an emphasis on practical implementation in real-world analytical contexts. Students will engage with the full data science pipeline — from data acquisition and preprocessing through model development, evaluation, and deployment — using industry-standard Python libraries and frameworks. This course bridges theoretical foundations in machine learning and statistical analysis with the applied computational skills demanded by contemporary data-driven industries.

---

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement end-to-end data science pipelines in Python, including data ingestion, cleaning, feature engineering, and visualization using libraries such as NumPy, pandas, and Matplotlib
- Develop, train, and evaluate supervised and unsupervised machine learning models using scikit-learn and related frameworks, applying appropriate metrics to assess model performance
- Construct and deploy foundational artificial intelligence systems, including neural network architectures, using deep learning frameworks such as TensorFlow or PyTorch
- Apply best practices in reproducible research and collaborative development, including version control, virtual environment management, and structured notebook documentation
- Critically assess the ethical implications of AI and data science applications, including concerns related to algorithmic bias, data privacy, and the societal impact of automated decision-making systems

### Prerequisites

Students must have successfully completed all of the following prior to enrollment:

- **COMP-22100 – Data Structures and Algorithms** (minimum grade: C+)
- **COMP-27300 – Introduction to Machine Learning** (minimum grade: C+)
- **MATH-21500 – Probability and Statistical Inference** (minimum grade: C)
- **MATH-20200 – Linear Algebra for Computing** (minimum grade: C)

Students without formal completion of COMP-27300 may petition for enrollment with demonstrated equivalent experience, subject to departmental approval. It is strongly recommended that students have prior familiarity with Python at an intermediate level before enrolling. Students who have not completed intermediate Python coursework are encouraged to complete the non-credit preparatory module offered through the College of Engineering prior to the start of term.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Midterm Examination | 20% | Closed-book written and computational exam covering data preprocessing, statistical analysis, and foundational machine learning concepts |
| Final Examination | 25% | Comprehensive closed-book examination including both conceptual questions and algorithm interpretation problems |
| Programming Assignments (×4) | 25% | Four individual assignments distributed throughout the semester, each targeting a specific stage of the data science pipeline |
| Group Project | 20% | A semester-long collaborative project in which teams of 3–4 students select a real-world dataset, define a research question, and produce a fully documented AI or data science solution with a final written report and oral presentation |
| Weekly Lab Submissions | 10% | Short structured lab exercises completed during scheduled laboratory sessions, assessed on correctness and code quality |

**Note on Academic Integrity:** All programming submissions are processed through automated plagiarism detection software. Students are encouraged to discuss approaches collaboratively but must submit independently authored code unless explicitly working within a designated group component. Refer to the Peculiar U Academic Integrity Policy (Section 7.4) for full guidelines.
