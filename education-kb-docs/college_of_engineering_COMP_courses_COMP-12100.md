## Course Description

### Course Description

COMP-12100: Linux Implementation/Administration Practicum is an advanced graduate-level course that provides intensive, hands-on training in the deployment, configuration, and ongoing administration of Linux-based systems within enterprise and research computing environments. Students engage directly with real-world scenarios encompassing system installation, network services configuration, security hardening, performance tuning, and automated infrastructure management. This practicum emphasizes operational competency and professional-grade decision-making, preparing students to assume senior-level roles in Linux systems administration and infrastructure engineering.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- **Design and deploy** production-ready Linux environments, including bare-metal installations, virtual machines, and containerized workloads, adhering to industry best practices for scalability and reliability
- **Configure and manage** core enterprise services including DNS, DHCP, NFS, SSH, web servers, and directory services such as LDAP and Active Directory integration
- **Implement comprehensive security frameworks** including SELinux/AppArmor policy management, firewall rule sets, intrusion detection systems, audit logging, and vulnerability mitigation procedures consistent with current CIS Benchmarks
- **Develop and maintain automation pipelines** using shell scripting, configuration management tools (such as Ansible or Puppet), and CI/CD integration to streamline system administration workflows at scale
- **Diagnose and resolve** complex system failures through structured troubleshooting methodologies, analyzing kernel logs, performance metrics, and network traffic to restore and optimize system operation

### Assessment Methods

Student performance in COMP-12100 is evaluated through a combination of practical demonstrations, written analyses, and collaborative project work reflecting the demands of professional Linux administration practice.

- **Lab Practicum Exercises (30%):** Weekly structured lab sessions require students to complete timed, graded administrative tasks within isolated virtual environments. Each exercise is evaluated on technical correctness, efficiency of approach, and documentation quality. Labs are submitted via the course's dedicated infrastructure portal.

- **Midterm Technical Examination (15%):** A written and practical midterm examination assesses students' command of core concepts covered in the first half of the term, including installation procedures, service configuration, and foundational security controls. Students must achieve a minimum score of 70% on this examination to continue in the practicum.

- **Security Hardening and Audit Project (20%):** Working in pairs, students receive a deliberately misconfigured Linux system and must perform a full security audit, produce a written vulnerability report, apply remediations, and present their findings to the class. The project is evaluated on technical rigor, report clarity, and the effectiveness of applied solutions.

- **Capstone Infrastructure Deployment Project (25%):** The capstone project requires each student to independently design, document, and deploy a multi-service Linux infrastructure meeting a detailed client specification provided by the instructors. Deliverables include a comprehensive system architecture document, a live demonstration, and a post-deployment administrative runbook.

- **Professional Reflective Portfolio (10%):** Throughout the term, students maintain a running portfolio documenting their lab experiences, challenges encountered, solutions developed, and professional growth. The portfolio is reviewed at midterm and submitted in final form during the last week of instruction.
