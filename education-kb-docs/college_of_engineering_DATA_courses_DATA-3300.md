## Course Description

### Course Description

DATA-3300: Practical Machine Learning provides students with a comprehensive, hands-on introduction to the design, implementation, and evaluation of machine learning systems using contemporary tools and programming frameworks. Students will explore a broad range of supervised and unsupervised learning techniques, gaining practical experience in applying these methods to real-world datasets across diverse domains. Emphasis is placed on developing sound methodological judgment, including model selection, performance evaluation, and the ethical implications of deploying machine learning systems in practice.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Implement and evaluate a range of supervised learning algorithms, including linear models, decision trees, ensemble methods, and neural networks, using industry-standard programming libraries
- Apply unsupervised learning techniques such as clustering, dimensionality reduction, and anomaly detection to unlabelled datasets
- Design and execute complete machine learning pipelines, encompassing data preprocessing, feature engineering, model training, hyperparameter tuning, and performance assessment
- Critically assess model outputs using appropriate evaluation metrics and validation strategies, and communicate findings clearly to both technical and non-technical audiences
- Identify and reason about ethical considerations in machine learning, including issues of bias, fairness, transparency, and responsible deployment of predictive systems

### Prerequisites

Students must have successfully completed the following before enrolling in DATA-3300:

- **DATA-2100: Foundations of Data Science** or equivalent
- **DATA-2210: Statistical Methods for Data Analysis** or equivalent
- **CS-2050: Programming for Data Applications** (proficiency in Python is strongly recommended)
- A minimum grade of C+ in all prerequisite courses is required

Students without a formal background in linear algebra are strongly encouraged to complete **MATH-2020: Linear Algebra and Its Applications** prior to enrollment, as familiarity with matrix operations and vector spaces will be assumed throughout the course.

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (4 × individual) | 30% |
| Midterm Examination | 20% |
| Group Project — Phase I: Proposal & Exploratory Analysis | 10% |
| Group Project — Phase II: Model Development & Evaluation | 20% |
| Group Project — Phase III: Final Report & Presentation | 15% |
| Participation & In-Class Exercises | 5% |

**Programming Assignments** are completed individually and require students to implement, train, and evaluate machine learning models using provided or self-sourced datasets. Submissions are made via the course repository platform and assessed on both correctness and code quality.

**The Midterm Examination** is a closed-book written assessment covering theoretical foundations, algorithmic principles, and conceptual application of machine learning methods addressed in the first half of the course.

**The Group Project** is completed in teams of three to four students and constitutes a substantial applied investigation of a machine learning problem of the team's choosing, subject to instructor approval. The project is assessed across three sequential phases culminating in a formal written report and a live presentation to the class.

### Required Materials

Students are required to obtain the following texts prior to the first week of class:

- Vanthorpe, C. R., & Osei-Mensah, D. (2021). *Learning from Data: Machine Learning in Theory and Practice* (3rd ed.). Lakebrook Academic Press. ISBN: 978-1-55234-871-4
- Iglesias-Brandt, S. (2022). *Applied Machine Learning with Python: Pipelines, Models, and Real-World Systems*. Northgate Technical Publishers. ISBN: 978-0-88472-305-9

The following text is recommended but not required:

- Farquhar, T., Miladinović, R., & Cheng, J. L. (2020). *The Ethical Machine: Fairness, Accountability, and Transparency in Automated Systems*. Caldwell University Press. ISBN: 978-1-60891-144-2

All required software tools, including Python 3.x, Jupyter Notebook, and relevant open-source libraries (scikit-learn, pandas, NumPy, Matplotlib), are freely available and installation instructions will be provided during the first class session. Students are expected to have access to a personal laptop capable of running these tools; computing cluster access for larger-scale assignments will be arranged through the College of Engineering.
