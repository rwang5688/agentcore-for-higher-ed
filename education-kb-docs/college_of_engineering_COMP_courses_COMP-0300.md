### Course Description

This course provides an in-depth examination of the internal structures and implementation strategies underlying modern operating systems, with emphasis on process management, memory hierarchies, concurrency, and file system architecture. Students engage with both theoretical frameworks and hands-on systems programming to develop a rigorous understanding of how operating systems mediate between hardware resources and application software. Advanced topics including virtualization, distributed OS concepts, and security mechanisms are explored through a combination of technical analysis and practical implementation exercises.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement core operating system components, including schedulers, memory managers, and inter-process communication mechanisms, demonstrating a thorough understanding of their structural interdependencies.
- Analyze and evaluate trade-offs in OS design decisions, including those related to performance, fault tolerance, scalability, and security in both single-system and distributed environments.
- Apply synchronization primitives and concurrency control techniques to construct correct, deadlock-free multi-threaded systems and reason formally about their correctness.
- Construct and debug low-level systems code in C and assembly, leveraging kernel interfaces and hardware abstractions to implement functional OS subsystems.
- Critically assess contemporary operating systems research literature and articulate how emerging challenges — such as cloud infrastructure, real-time constraints, and hardware heterogeneity — are shaping OS design paradigms.

### Assessment Methods

| Component | Weight |
|---|---|
| Midterm Examination | 20% |
| Final Examination | 25% |
| Implementation Projects (×3) | 35% |
| Research Paper & Presentation | 12% |
| Participation & Lab Exercises | 8% |

**Examinations:** Two written examinations assess conceptual understanding, design analysis, and problem-solving across all major course topics. Both exams include a mix of short-answer, diagram-based, and extended technical response questions.

**Implementation Projects:** Three substantial programming projects require students to build functional OS components — including a process scheduler, a virtual memory subsystem, and a simplified file system — within a provided kernel development environment. Projects are evaluated on correctness, efficiency, code clarity, and accompanying design documentation.

**Research Paper & Presentation:** Students select an approved topic in advanced or emerging OS research, produce a formal technical paper of approximately 2,500–3,500 words, and deliver a 15-minute presentation to the class with a question-and-answer period. Topics must be approved by the fifth week of term.

**Participation & Lab Exercises:** Weekly lab sessions reinforce lecture content through structured exercises. Attendance and active engagement are recorded; short lab reports may be required at the discretion of the supervising instructor.
