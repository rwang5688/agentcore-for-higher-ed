### Course Description

This course provides a rigorous introduction to the foundational principles and algorithms of machine learning, covering supervised learning, unsupervised learning, and introductory reinforcement learning paradigms within both theoretical and applied contexts. Students will develop practical competency in designing, implementing, and evaluating machine learning models using contemporary programming frameworks and real-world datasets. Emphasis is placed on the mathematical underpinnings of core algorithms, responsible model development, and critical interpretation of model performance and limitations.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Explain and compare the core families of machine learning algorithms — including regression, classification, clustering, and dimensionality reduction — and select appropriate methods for a given problem domain.
- Implement machine learning pipelines from data preprocessing through model training, validation, and deployment using standard programming libraries and tools.
- Analyse model performance using appropriate evaluation metrics such as precision, recall, F1-score, ROC-AUC, and cross-validation techniques, and diagnose common failure modes including overfitting and underfitting.
- Apply foundational mathematical concepts — including linear algebra, probability, and calculus-based optimisation — to understand the derivation and behaviour of machine learning algorithms.
- Critically assess the ethical implications of machine learning systems, including issues of algorithmic bias, fairness, transparency, and the societal impact of automated decision-making.

### Assessment Methods

| Component | Weight | Details |
|---|---|---|
| Programming Assignments (×4) | 35% | Four structured coding assignments requiring implementation of machine learning algorithms and analysis of results on provided datasets. |
| Midterm Examination | 20% | Written examination covering theoretical concepts, algorithm derivations, and short applied problems from weeks one through seven. |
| Group Project | 25% | Teams of three to four students will identify a real-world problem, curate or source an appropriate dataset, develop and evaluate a machine learning solution, and present findings in both a written report and a live demonstration. |
| Final Examination | 15% | Comprehensive written examination encompassing all course material, with emphasis on synthesis, model comparison, and critical analysis. |
| Participation & Reflection Journals | 5% | Weekly short written reflections (300–400 words) responding to assigned readings or in-class discussions, assessed on engagement and critical thinking. |

All programming assignments must be submitted via the university's course management portal by 11:59 PM on the stated due date. Late submissions will be penalised at a rate of 10% per calendar day unless a formal extension has been approved in advance.
