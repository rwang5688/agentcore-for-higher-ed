## Course Description

### Course Description

This course provides a foundational introduction to the design, implementation, and management of local area networks (LANs), equipping students with the essential knowledge and practical skills required to understand modern networking environments. Topics include network topologies, transmission media, network protocols, switching technologies, and basic network security principles. Students will gain hands-on experience configuring and troubleshooting LAN infrastructure through guided laboratory exercises.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Identify and describe common LAN topologies, architectures, and the physical and logical components that comprise a functional local area network
- Explain the role of key networking protocols and standards, including the OSI and TCP/IP models, Ethernet, and IEEE 802 standards, as they apply to LAN environments
- Configure and manage basic network devices, including switches, routers, and wireless access points, using industry-standard command-line and graphical interfaces
- Analyze and troubleshoot common LAN connectivity issues using appropriate diagnostic tools and systematic problem-solving methodologies
- Recognize fundamental LAN security vulnerabilities and apply basic protective measures to safeguard network resources and data integrity

### Assessment Methods

Student performance in this course will be evaluated through a combination of theoretical assessments and practical demonstrations, as follows:

- **Laboratory Assignments (30%):** Weekly hands-on lab exercises conducted in the Peculiar U networking laboratory, requiring students to configure devices, build network topologies, and document their findings in structured lab reports
- **Midterm Examination (20%):** A written examination covering foundational concepts including networking models, topologies, transmission media, and Ethernet standards administered at the midpoint of the semester
- **Quizzes (15%):** Short, regularly scheduled quizzes designed to reinforce lecture content and assess ongoing comprehension of course material
- **Network Design Project (20%):** A capstone group project in which student teams plan, design, and present a LAN solution for a fictional small-to-medium enterprise scenario, including topology diagrams, equipment selection justification, and a basic security plan
- **Final Examination (15%):** A comprehensive written and practical examination covering all course content, including a hands-on component assessed in the networking lab
