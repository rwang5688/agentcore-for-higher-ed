## Course Description

### Course Description

This advanced graduate-level course provides a comprehensive examination of mobile application development for Apple's iOS 5 platform, with a focus on designing, building, and deploying feature-rich applications for the iPhone. Students will engage with the full development lifecycle using Xcode, Objective-C, and the Cocoa Touch framework, applying industry-standard practices to produce polished, market-ready applications. The course emphasizes both technical proficiency and user-centered design principles, preparing students to operate effectively in professional mobile development environments.

---

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement fully functional iPhone applications using Xcode IDE, the iOS 5 SDK, and the Objective-C programming language
- Apply core iOS 5 frameworks—including UIKit, Core Data, and Core Location—to build applications that leverage native device hardware and software capabilities
- Evaluate and implement effective user interface and user experience design patterns consistent with Apple's Human Interface Guidelines
- Integrate networking functionality, RESTful APIs, and persistent local storage into mobile application architectures
- Deploy, test, and debug applications using the iOS Simulator and physical devices, and demonstrate familiarity with the Apple App Store submission process

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (5 total) | 35% |
| Midterm Examination | 15% |
| Group Application Project | 30% |
| Individual Technical Report | 10% |
| Participation & Code Reviews | 10% |

**Programming Assignments:** Five structured assignments will be issued across the semester, each targeting a specific iOS 5 development competency such as table views, Core Data integration, or location-based services. Assignments are submitted via the course repository and evaluated on functionality, code quality, and adherence to Apple design standards.

**Midterm Examination:** A written and practical examination covering iOS 5 architecture, Objective-C language fundamentals, memory management, and UIKit components. Students will be required to trace, analyze, and debug provided code segments in addition to answering conceptual questions.

**Group Application Project:** Working in teams of two to three, students will conceptualize, design, develop, and present a complete, deployable iPhone application. A project proposal, design documentation, progress milestone, and final demonstration are all required deliverables. Peer evaluations will contribute to individual grades within the group component.

**Individual Technical Report:** A formal written report (minimum 3,000 words) analyzing the architectural decisions made during the group project, comparing alternative implementation approaches considered, and reflecting critically on the development process using relevant academic and industry literature.

**Participation & Code Reviews:** Students are expected to engage actively in weekly code review sessions, offering and receiving constructive technical feedback on peers' work. Consistent, meaningful contributions to in-class discussions and lab sessions will be assessed by the instructional team.
