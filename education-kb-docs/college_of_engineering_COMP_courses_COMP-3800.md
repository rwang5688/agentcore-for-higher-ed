## Course Description

### Course Description

COMP-3800: Computer Networks provides a rigorous examination of the principles, architectures, and protocols that underpin modern data communication systems. Students will explore the layered design of networks from physical transmission media through application-layer services, with emphasis on the Internet's TCP/IP protocol suite. The course integrates theoretical foundations with practical laboratory exercises, equipping students to analyze, design, and troubleshoot real-world networked systems.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Explain the function and interaction of each layer within the OSI and TCP/IP reference models, articulating how data encapsulation and decapsulation occurs across layers
- Analyze core networking protocols — including IP, TCP, UDP, HTTP, DNS, and routing protocols such as OSPF and BGP — describing their mechanisms, trade-offs, and appropriate use cases
- Design and evaluate network topologies for small-to-medium scale environments, incorporating considerations of bandwidth, latency, reliability, and security
- Apply socket programming techniques to implement basic networked client-server applications in a high-level programming language
- Diagnose common network failures and performance bottlenecks using industry-standard tools such as Wireshark, traceroute, and network simulators

---

### Prerequisites

Students must have completed the following before enrolling in COMP-3800:

- **COMP-2210: Data Structures and Algorithms** — foundational understanding of algorithmic complexity and data organization is essential for analyzing protocol behavior and network performance
- **COMP-2450: Operating Systems Fundamentals** — familiarity with process management, concurrency, and I/O operations is required for understanding socket programming and kernel-level networking
- **MATH-2110: Discrete Mathematics** — proficiency in logic, graph theory, and probability is necessary for routing algorithm analysis and network reliability modeling

Students lacking any of the above prerequisites must obtain written instructor approval prior to registration.

### Assessment Methods

| Component | Weight | Details |
|---|---|---|
| Midterm Examination | 20% | Written exam covering OSI/TCP-IP models, physical and data-link layers, IP addressing, and subnetting |
| Final Examination | 25% | Comprehensive written exam with emphasis on transport and application layers, routing protocols, and network security |
| Laboratory Assignments (×5) | 25% | Hands-on exercises using Cisco Packet Tracer and Wireshark; topics include packet capture analysis, subnetting, and basic router configuration |
| Programming Project | 20% | Multi-part project requiring students to implement a functional client-server application with socket programming; final submission includes source code and a technical report |
| Quizzes (×4) | 10% | Short in-class quizzes administered throughout the semester to reinforce lecture material and identify areas for review |

*Late submissions are subject to a penalty of 10% per calendar day unless a formal extension has been granted by the supervising instructor. All examinations must be completed in-person unless an approved accommodation is on file with the Office of Student Affairs.*
