## Course Description

### Course Description

DATA-1600: Data Science: R Basics provides students with a rigorous foundation in the R programming language as applied to real-world data science workflows, with an emphasis on data manipulation, statistical computing, and reproducible research practices. Students will explore core R syntax, data structures, and widely used packages within the tidyverse ecosystem to clean, transform, and visualize complex datasets. This course bridges theoretical statistical knowledge with practical computational implementation, preparing students for advanced data science inquiry at the graduate and professional level.

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate proficiency in core R programming constructs, including data types, control flow, functions, and object-oriented principles as applied in data science contexts
- Import, clean, and transform structured and semi-structured datasets using industry-standard R packages such as dplyr, tidyr, and readr
- Produce publication-quality data visualizations using ggplot2, applying principles of effective and ethical data communication
- Conduct and interpret foundational statistical analyses in R, including regression modelling, hypothesis testing, and exploratory data analysis
- Develop fully reproducible research workflows using R Markdown and version control integration, adhering to open science best practices

### Prerequisites

### Assessment Methods

| Component | Weight |
|---|---|
| Weekly Lab Assignments (10 × 4%) | 40% |
| Midterm Examination | 15% |
| Reproducible Research Project (individual) | 20% |
| Collaborative Data Analysis Portfolio (group) | 15% |
| Final Examination | 10% |

**Weekly Lab Assignments** are structured coding exercises submitted via the course's designated R environment, assessing incremental mastery of programming concepts introduced in lecture.

**Midterm and Final Examinations** are closed-book, timed assessments conducted in the university computer lab, testing students' ability to write, debug, and interpret R code under examination conditions.

**Reproducible Research Project** requires each student to independently identify a publicly available dataset, formulate an analytical question, conduct a full analysis in R, and present findings in a polished R Markdown report suitable for peer review.

**Collaborative Data Analysis Portfolio** tasks groups of three to four students with producing a multi-stage analytical report addressing a discipline-specific problem set provided by the instructional team, culminating in a formal presentation to the cohort.
