## Course Description

### Course Description

COMP-2600 introduces students to the principles and practices of building dynamic, data-driven web applications using contemporary server-side and client-side technologies. Students will develop proficiency in integrating databases, scripting languages, and web frameworks to create interactive, responsive web experiences. Emphasis is placed on industry-standard development practices, including version control, security considerations, and the deployment of functional web projects.

### Learning Objectives

By the end of this course, students will be able to:

- Design and implement dynamic web pages using server-side scripting languages and templating systems to generate content from live data sources
- Construct and query relational databases to support persistent, user-driven web application functionality
- Apply client-side scripting techniques, including DOM manipulation and asynchronous communication (AJAX/Fetch API), to enhance interactivity without full page reloads
- Evaluate and implement fundamental web security practices, including input validation, authentication mechanisms, and protection against common vulnerabilities such as SQL injection and cross-site scripting (XSS)
- Develop and deploy a complete, multi-page dynamic web application incorporating version control workflows and basic deployment procedures

### Prerequisites

Students must have successfully completed the following prior to enrollment:

- **COMP-1100: Introduction to Programming** or equivalent — foundational programming concepts including variables, control flow, and functions
- **COMP-1250: Web Fundamentals** or equivalent — working knowledge of HTML5 and CSS3
- A minimum cumulative GPA of 2.0 is recommended

### Assessment Methods

| Component | Weight |
|---|---|
| Programming Assignments (5–6 individual assignments) | 35% |
| Midterm Examination | 15% |
| Final Examination | 20% |
| Group Web Application Project | 25% |
| Participation & Lab Exercises | 5% |

**Programming Assignments** are submitted bi-weekly and assess individual mastery of core techniques covered in lectures and labs. **The Group Web Application Project** is a semester-long, multi-phase project in which teams of three to four students plan, build, and deploy a fully functional dynamic web application; deliverables include a project proposal, progress check-ins, a final codebase submission, and a live demonstration. **Examinations** are written and may include short-answer, code-reading, and code-writing components.

All three texts are available for short-term loan through the Peculiar U Library. Students will also require access to a personal computer capable of running a local development environment; setup instructions are provided in the course orientation materials available on the course management system prior to the first day of class.
