## Course Description

### Course Description

This course provides a comprehensive introduction to the principles and practices of Android application development using modern tools and frameworks, including the Android SDK, Android Studio, and the Kotlin programming language. Students will explore the full lifecycle of mobile application development, from design and prototyping through implementation, testing, and deployment on the Google Play platform. Emphasis is placed on industry-standard best practices, user interface design, and the integration of device hardware features and cloud-based services.

### Learning Objectives

By the end of this course, students will be able to:

- Design, develop, and deploy fully functional Android applications using Kotlin and the Android Studio development environment
- Apply core Android architectural patterns, including Model-View-ViewModel (MVVM), to build scalable and maintainable mobile applications
- Integrate external APIs, databases, and cloud services into Android applications to support dynamic and data-driven functionality
- Implement responsive and accessible user interfaces that adhere to Material Design guidelines and support a variety of screen sizes and device configurations
- Evaluate application performance, conduct systematic debugging, and apply testing strategies including unit and instrumented testing to ensure software quality

### Prerequisites

Students enrolling in COMP-1000 are expected to have completed the following or demonstrate equivalent competency:

- **COMP-320: Object-Oriented Programming** or equivalent programming experience in Java, Kotlin, or a comparable language
- **COMP-410: Data Structures and Algorithms** — foundational understanding of data structures is essential for efficient application logic
- **COMP-480: Software Engineering Principles** — familiarity with software development lifecycles, version control (Git), and collaborative project workflows
- Students without formal prerequisites may seek instructor approval by submitting a portfolio of prior programming work for review

### Assessment Methods

| Assessment Component | Weight |
|---|---|
| Programming Assignments (5 total) | 35% |
| Midterm Examination | 15% |
| Group Application Project | 30% |
| Final Examination | 15% |
| Participation & Code Reviews | 5% |

**Programming Assignments:** Five individual assignments are distributed throughout the semester, each targeting a specific development skill set such as UI layout construction, database integration, and API consumption. Assignments are submitted via the course's designated version control repository.

**Midterm Examination:** A written and practical examination covering foundational concepts including Android architecture components, the Activity and Fragment lifecycle, and Kotlin language fundamentals.

**Group Application Project:** Teams of three to four students will conceptualize, design, and develop a fully functional Android application of their choosing. Project milestones include a design document submission, a mid-project progress review, and a final demonstration presented to the class and evaluated by the instructional team. A peer evaluation component is included.

**Final Examination:** A comprehensive written and practical examination covering all course material, with emphasis on architectural decisions, debugging scenarios, and the evaluation of code samples.

**Participation & Code Reviews:** Students are expected to engage in structured peer code review sessions and contribute meaningfully to in-class discussions and lab activities throughout the semester.
