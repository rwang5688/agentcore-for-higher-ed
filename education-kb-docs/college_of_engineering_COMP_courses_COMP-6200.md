### Course Description

This course provides a rigorous and comprehensive exploration of iOS application development using the Swift programming language within the iOS 10 ecosystem, with emphasis on professional-grade software design and implementation practices. Students will engage with Apple's Xcode development environment, UIKit frameworks, and the Model-View-Controller architectural paradigm to construct fully functional, deployable mobile applications. Advanced topics including data persistence, networking, multithreading, and interface design are examined within the context of real-world application development workflows and industry standards.

---

### Learning Objectives

Upon successful completion of this course, students will be able to:

- Design and implement robust, well-structured iOS applications using Swift, applying object-oriented and protocol-oriented programming principles to solve complex software engineering problems.
- Utilize core iOS 10 frameworks — including UIKit, Core Data, and Core Location — to build feature-rich applications that leverage device hardware and operating system capabilities.
- Apply the Model-View-Controller (MVC) and related architectural patterns to organize application codebases in a maintainable, scalable, and testable manner consistent with industry best practices.
- Integrate networking and RESTful API communication into iOS applications, handling asynchronous data retrieval, JSON parsing, and error management effectively and securely.
- Evaluate and implement appropriate data persistence strategies, including Core Data, NSUserDefaults, and file system storage, while demonstrating an understanding of application lifecycle management and memory efficiency.

### Prerequisites

Students must have successfully completed the following prior to enrollment in COMP-6200:

- **COMP-4810: Mobile Computing Fundamentals** or equivalent — a foundational understanding of mobile platform architecture and development environments is required.
- **COMP-4450: Object-Oriented Software Design** — proficiency in object-oriented design principles, design patterns, and software architecture is expected.
- **COMP-3300: Data Structures and Algorithms** — students must demonstrate competency in core algorithmic thinking and data management concepts.

Students with prior demonstrable experience in Swift or Objective-C development may petition the department for prerequisite waiver consideration. Familiarity with macOS and the Xcode IDE is strongly recommended prior to the start of the semester.

### Assessment Methods

Student performance will be evaluated through the following components:

| Assessment | Weight |
|---|---|
| Programming Assignments (5 individual assignments) | 30% |
| Midterm Examination | 15% |
| Project Milestone Reports (2 written submissions) | 10% |
| Final Capstone Application Project | 35% |
| Participation & Code Review Sessions | 10% |

**Programming Assignments** are assigned bi-weekly and require students to implement specific iOS features and frameworks as covered in lecture. Submissions must include documented source code and a brief technical write-up justifying key design decisions.

**Midterm Examination** will assess theoretical knowledge of Swift language features, iOS 10 architecture, memory management, and framework usage through a combination of multiple-choice, short-answer, and code-analysis questions.

**Project Milestone Reports** are written documents submitted at designated points during the semester, outlining the design, architecture, and progress of each student's capstone project. Reports must conform to the department's technical writing standards.

**Final Capstone Application Project** requires students to design, develop, and present a fully functional iOS 10 application of their own conception. The project is evaluated on code quality, architectural integrity, user interface design, functionality, and a live demonstration presented to faculty evaluators during the final examination period.

**Participation & Code Review Sessions** involve active engagement in structured peer code reviews, in-class debugging exercises, and technical discussions. Students are expected to provide and receive constructive feedback in a professional manner.
