## Course Description

### Course Description

COMP-0400: Algorithms Part I provides a rigorous introduction to the design, analysis, and implementation of fundamental algorithms and data structures at the advanced undergraduate level. Students will explore core algorithmic paradigms including divide-and-conquer, dynamic programming, and greedy strategies, developing the mathematical and computational tools necessary to evaluate algorithm efficiency and correctness. This course serves as a foundational pillar for advanced study in computer science, preparing students to reason formally about computational problems and their solutions.

---

### Learning Objectives

By the end of this course, students will be able to:

- Analyze the time and space complexity of algorithms using asymptotic notation, including Big-O, Big-Omega, and Big-Theta classifications
- Design and implement algorithms using core paradigms such as divide-and-conquer, dynamic programming, and greedy methods, selecting appropriate strategies for a given problem
- Evaluate the correctness of algorithms through formal proof techniques, including loop invariants, induction, and recurrence relation analysis
- Apply and compare fundamental data structures — including heaps, balanced binary search trees, hash tables, and graphs — selecting appropriate structures to optimize algorithmic performance
- Formulate and solve novel computational problems by reducing them to known algorithmic frameworks and critically assessing trade-offs between competing solutions

### Prerequisites

Students must have successfully completed all of the following prior to enrollment:

- **COMP-0301: Data Structures and Abstract Data Types** or equivalent, with a minimum grade of C+
- **COMP-0315: Discrete Mathematics for Computer Science**, covering combinatorics, graph theory, and proof techniques
- **MATH-0220: Linear Algebra** or **MATH-0210: Calculus II**, demonstrating sufficient mathematical maturity for formal analysis
- Familiarity with at least one high-level programming language (Python, Java, or C++ recommended) as demonstrated through prior coursework

Students who have not completed the listed prerequisites must obtain written permission from the course instructor or the Department of Computer Science undergraduate advisor before enrolling.

### Assessment Methods

| Component | Weight | Description |
|---|---|---|
| Problem Sets (6 total) | 35% | Weekly written and coding assignments requiring formal algorithm design and complexity analysis |
| Midterm Examination | 20% | In-class written exam covering asymptotic analysis, recursion, and foundational paradigms |
| Algorithm Design Project | 20% | A multi-stage individual or paired project requiring the design, implementation, and written analysis of an original algorithmic solution to a real-world problem |
| Final Examination | 20% | Comprehensive written exam emphasizing synthesis across all course topics |
| Participation & Recitation | 5% | Active engagement in weekly recitation sections, including in-class problem-solving exercises |

Problem sets must be submitted via the course portal by the posted deadlines. Late submissions will be penalised at a rate of 10% per 24-hour period unless a formal extension has been approved. All examinations are closed-book unless otherwise specified by the administering instructor.
