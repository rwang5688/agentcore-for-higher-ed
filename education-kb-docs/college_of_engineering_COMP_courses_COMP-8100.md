## Course Description

### Course Description

COMP-8100 provides an accelerated and rigorous introduction to the foundational principles of computer science through the practical application of three industry-relevant programming languages: C, PHP, and JavaScript. Students will develop a comprehensive understanding of programming paradigms, algorithmic thinking, and software development practices as applied across low-level systems, server-side web environments, and client-side interactive applications. This course is designed for graduate-level students entering the discipline from adjacent technical fields who require a structured and intensive foundation in computational thinking and modern programming practice.

---

### Learning Objectives

By the end of this course, students will be able to:

- Demonstrate proficiency in the syntax, semantics, and core programming constructs of C, PHP, and JavaScript, including variables, control flow, functions, and data structures
- Apply fundamental computer science concepts — including memory management, recursion, object-oriented design, and algorithm complexity — within each of the three target languages
- Design, implement, and debug multi-language software solutions that integrate systems-level logic (C), server-side scripting (PHP), and dynamic front-end behaviour (JavaScript)
- Analyse and evaluate the relative strengths, limitations, and appropriate use cases of each programming language within the broader software development ecosystem
- Communicate technical design decisions and document code clearly and professionally in accordance with established software engineering standards

---

### Prerequisites

Given the graduate-level designation of COMP-8100, students are expected to have satisfied the following prerequisites prior to enrolment:

- Completion of a Bachelor's degree in Computer Science, Software Engineering, Information Technology, Mathematics, or a closely related discipline, or demonstrated equivalent professional experience
- Familiarity with basic computational concepts such as binary representation, logic gates, and algorithmic problem-solving at the undergraduate level
- Prior exposure to at least one high-level programming language (e.g., Python, Java, or MATLAB) as evidenced by coursework, professional experience, or departmental placement assessment
- Completion of COMP-5010 (Foundations of Computational Logic) or COMP-5200 (Discrete Structures for Computing) or instructor consent

Students who are uncertain whether their background satisfies these requirements are encouraged to contact the Department of Computer Science for an advisory consultation prior to registration.

### Assessment Methods

Student performance in COMP-8100 will be evaluated through a combination of formative and summative assessments designed to reflect both conceptual understanding and applied programming competence.

| Assessment Component | Weight | Details |
|---|---|---|
| Programming Assignments (×6) | 30% | Six individual assignments distributed evenly across the semester, each targeting a specific language or cross-language integration task |
| Midterm Examination | 20% | Written and practical examination covering C and PHP modules; includes both theoretical questions and a supervised coding component |
| Group Software Project | 25% | A collaborative project requiring teams of 3–4 students to design and deliver a functional web application integrating all three languages; assessed on functionality, code quality, and documentation |
| Final Examination | 20% | Comprehensive written and practical examination covering all three languages and overarching computer science concepts addressed throughout the course |
| Participation & Code Reviews | 5% | Active engagement in peer code review sessions and in-class technical discussions |

All programming assignments must be submitted via the departmental version-control platform. Late submissions will incur a penalty of 10% per calendar day unless an extension has been formally approved by the course coordinator.
