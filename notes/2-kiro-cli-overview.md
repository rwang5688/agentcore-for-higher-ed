# Module 2: Getting Started with Kiro CLI

## Summary

Informational module. Explains the `.kiro/` directory structure, MCP servers (`aws-docs`, `strands-agents`), steering files, and Kiro CLI slash commands (`/model`, `/tools`, `/compact`).

## Quick Commands (copy-paste)

Start a chat session:

```bash
kiro-cli chat
```

Switch models (inside chat):

```
/model
```

Verify MCP servers started (look for `search_documentation`, `fetch_doc`):

```
/tools
```

Free context space between modules:

```
/compact
```

## Key Takeaways

- `kiro-cli chat` starts an interactive session
- `/tools` verifies MCP servers started correctly
- `/compact` between modules to free context space
- Pre-installed packages: `bedrock-agentcore-starter-toolkit`, `strands-agents[bedrock]`, `bedrock-agentcore`
